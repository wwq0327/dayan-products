核心高频词（必须掌握）

之
①代词，他/她/它 → 愿驰千里足，送之还故乡
②助词，的 → 小大之狱，虽不能察，必以情
③助词，主谓间取消独立性 → 甚矣，汝之不惠
④动词，往 → 之次所旁丛祠中
其
①代词，他的/那个 → 其一犬坐于前
②语气词，表揣测 → 其真无马耶
③代词，自己 → 策之不以其道
④指示代词，那个 → 其后数年
以
①介词，用/拿 → 以刀劈狼首
②介词，因为 → 以是人多以书假余
③连词，来 → 俯身倾耳以请
④介词，凭借 → 以我酌油知之
而
①连词，表并列 → 温故而知新
②连词，表转折 → 人不知而不愠
③连词，表递进 → 登高而招见者远
④连词，表修饰 → 默而识之
为
①动词，做 → 为一说，使与书俱
②介词，给 → 为我击破沛公军
③动词，成为 → 子为布衣
④语气词，呢 → 何以哉
