一、古诗词鉴赏考什么

中考古诗词鉴赏主要考查五大核心要素：意象、意境、语言、手法、情感。掌握这五大要素，就抓住了古诗词鉴赏的核心。

二、第一要素：意象

① 什么是意象

意象是寄托了诗人情感的客观物象。简单说就是：融入了诗人情感的景物。

② 常见意象分类

思乡类

月亮 → 思乡、团圆　　鸿雁 → 书信、思念　　柳树 → 离别　　笛声 → 思乡

送别类

长亭 → 送别　　孤帆 → 远行　　杨柳 → 惜别　　酒 → 饯行

爱国类

烽火 → 战争　　山河 → 祖国　　杜鹃 → 悲愤　　投笔 → 从军

愁苦类

梧桐 → 孤独　　雨 → 愁绪　　落花 → 凋零　　秋风 → 悲凉

高洁类

梅花 → 坚韧　　菊花 → 隐逸　　青松 → 气节　　明月 → 高洁

③ 意象作用答题公式

公式：点明意象 + 分析特点 + 指出情感 + 表达效果
【例题】"月落乌啼霜满天"中"月"这个意象有什么作用？
"月"在诗中点明时间是深夜，渲染了寂静凄凉的环境氛围，烘托了诗人漂泊在外的孤独与惆怅之情，奠定了全诗悲凉的基调。

三、第二要素：意境

① 什么是意境

意境是诗人的主观情感与客观景物相融合而形成的一种艺术境界。简单说就是：诗歌中呈现的整体画面感。

② 常见意境术语

意境类型特点常见意象
萧瑟凄凉秋季肃杀、孤独寂寞枯藤、老树、乌鸦、夕阳
雄浑壮阔气势磅礴、意境高远大漠、长河、落日、孤城
清新明丽明亮柔和、生机盎然春风、春雨、桃花、流水
含蓄内敛言有尽而意无穷残月、寒鸦、孤灯
闲适恬淡悠然自得、超然物外山林、溪水、白云、飞鸟
低沉婉约忧愁细腻、缠绵悱恻细雨、轻烟、垂柳、落花

③ 意境作用答题公式

公式：描述画面 + 点明意境特点 + 指出情感作用 + 表达效果
【例题】分析"大漠孤烟直，长河落日圆"一联的意境。
诗句描绘了一幅边塞特有的壮阔雄浑画面：茫茫大漠上一缕狼烟直冲云天，远处黄河横贯其间，一轮落日浑圆悬挂天际。这一联展现了边塞的雄奇壮阔，烘托出诗人塞外生活的孤寂与苍凉，也隐含着诗人胸襟的博大。

四、第三要素：语言

① 语言特点类型

语言风格代表诗人特点
沉郁顿挫杜甫忧国忧民，节奏舒缓，富有变化
豪迈奔放李白想象丰富，气势磅礴，夸张奇特
婉约细腻李清照、柳永柔美动人，情感细腻，含蓄内敛
清新自然陶渊明、王维质朴平淡，意境高远，富有哲理
悲壮苍凉岑参、高适边塞风情，慷慨激昂，格调高昂

② 炼字类题目答题公式

公式：释义 + 手法 + 内容 + 情感 + 效果
【例题】"春风又绿江南岸"中"绿"字好在哪里？
"绿"字是形容词动用，意思是"使……变绿"。生动形象地写出了春风吹过、江南大地一片翠绿的景象，表达了诗人对春天的喜爱之情，同时"绿"字色彩鲜明，给人强烈的视觉冲击力。

③ 关键词赏析公式

公式：一拆（拆开原词）→ 二换（换成近义词）→ 三比较（比较表达效果差异）→ 四总结（总结表达优势）

五、第四要素：手法

① 常见表现手法

手法定义经典示例
借景抒情借助景物描写来抒发感情"明月松间照，清泉石上流"
托物言志借事物来表达自己的志向"零落成泥碾作尘，只有香如故"
借古讽今借古代人事来讽刺当今"东风不与周郎便，铜雀春深锁二乔"
对比烘托用对比或陪衬来突出主体"朱门酒肉臭，路有冻死骨"
虚实结合现实与想象相互交织"湖月照我影，送我至剡溪"
动静结合动态描写与静态描写结合"月出惊山鸟，时鸣春涧中"
卒章显志结尾点明主旨"先天下之忧而忧，后天下之乐而乐"

② 手法作用答题公式

公式：点明手法 + 分析内容 + 指出情感 + 表达效果
【例题】"但愿人长久，千里共婵娟"用了什么手法？有什么作用？
这两句用了借景抒情（情景交融）的手法。诗人借"明月"和"婵娟"这两个意象，表达了与亲人即使相隔千里也能共赏明月的美好祝愿，情感乐观旷达，既表现了对亲人的思念，又体现了诗人豁达开朗的人生态度。

六、第五要素：情感

① 古诗词常见情感分类

离别之情

代表作品：《送杜少府之任蜀州》《白雪歌送武判官归京》
情感特点：昂扬向上（"海内存知己，天涯若比邻"）vs 缠绵悱恻（"执手相看泪眼，竟无语凝噎"）

思乡之情

代表作品：《静夜思》《月夜忆舍弟》
情感特点：孤独惆怅、渴望团圆、岁月流逝感

爱国之情

代表作品：《过零丁洋》《春望》
情感特点：忧国忧民、建功立业、壮志难酬

山水之情

代表作品：《望岳》《使至塞上》
情感特点：热爱自然、追求自由、超然物外

怀古之情

代表作品：《念奴娇·赤壁怀古》《永遇乐·京口北固亭怀古》
情感特点：借古讽今、吊古伤今、壮志难酬

② 情感答题公式

公式：概括情感类别 + 具体分析诗句 + 点明诗人情感态度
【例题】《渔家傲·秋思》表达了什么情感？
这首词表达了戍边将士的复杂情感：①思乡之情（"浊酒一杯家万里"）；②忧国之情（"燕然未勒归无计"）；③壮志难酬的悲愤（"羌管悠悠霜满地"）。全词借边塞秋景，抒发了将士们既思念家乡、又以国事为重的矛盾心情，格调悲壮苍凉。

七、综合解题四步法

第一步：看题目和作者

题目往往透露写作对象和情感基调；作者决定了语言风格和常用手法。

第二步：读注释

注释往往解释难懂的词语、交代写作背景，是理解诗歌的重要线索。

第三步：抓意象，析意境

圈画诗歌中的核心意象，描述画面，分析意境特点。

第四步：归类别，答情感

将诗歌情感归类（离别/思乡/爱国/山水/怀古），用公式组织答案。

八、真题实战

【2024南充中考】阅读《渡荆门送别》，回答问题：

问题1：分析颔联的意境。

参考答案：颔联"山随平野尽，江入大荒流"描绘了山势逐渐消失在广袤的平原上，江水流入广阔荒原的壮阔景象。这一联展现了祖国山河的雄奇壮阔，表达了诗人离开故乡、游历四方的豪情壮志，情景交融，意境高远。

问题2：尾联"仍怜故乡水，万里送行舟"用了什么手法？表达了什么情感？

参考答案：尾联用了拟人手法，将故乡的水拟人化，说水"送"诗人远行，含蓄地表达了诗人对故乡的思念和不舍之情，以水衬情，委婉深沉。
