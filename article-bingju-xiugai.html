六大类型·分类突破

类型一：成分残缺

主语残缺
✗ 通过这次活动，使我明白了团结的重要性。
✓ 这次活动使我明白了团结的重要性。
【技巧】"通过"和"使"同时出现，淹没了主语，删除其一即可。
宾语残缺
✗ 学校要努力提高教学质量。
✓ 学校要努力提高教学质量和水平。
谓语残缺
✗ 看到这张照片，不禁想起了那一幕。
✓ 看到这张照片，我不禁想起了那一幕。

类型二：语序不当

多项定语顺序
✗ 花园里盛开着美丽的五颜六色的花。
✓ 花园里盛开着五颜六色的美丽的花。
【顺序】范围+数量+形容词+名词（口诀：数形色名）
关联词语位置
✗ 既然你错了，就应该承认。
✓ 你既然错了，就应该承认。

类型三：搭配不当

主谓搭配
✗ 春天的成都大地万紫千红，鸟语花香。
✓ 春天的成都大地万紫千红
动宾搭配
✗ 我们要树立起攻坚困难的决心。
✓ 我们要树立克服困难的决心。
主宾搭配
✗ 雾凇是吉林省的天然的空气净化器。
✓ 雾凇是吉林省天然的空气净化器。

类型四：表意不明

✗ 母亲节那天，我送给妈妈一束花和一张卡片。
✓ 母亲节那天，我送给妈妈一束花，并附带一张卡片。
【歧义】"一束花和一张卡片"不知是送给妈妈还是送给妈妈和奶奶
✗ 这件事谁都不同意。
✓ 这件事没有人同意。（表意不明）

类型五：不合逻辑

✗ 能否努力是取得成绩的关键。
✓ 努力是取得成绩的关键。
【两面对一面】"能否"是两面对一面，应改为"努力"
✗ 我用了半个小时，才到达图书馆。
✓ 我用了半个小时，才到达图书馆。（逻辑问题：半小时太久吗？）

类型六：结构混乱

✗ 这件事使我想起了许多事。
✓ 这件事让我想起了许多往事。
💡 病句快速判断口诀

一看搭配（主谓/动宾/主宾）；二看语序（定语/状语/关联词位置）；三看成分（主语/谓语/宾语是否残缺）；四看逻辑（两面对一面/重复啰嗦）；五看结构（句式杂糅）。
