📝 文言文虚词用法18讲

之·其·而·于·以·乃·盖·何·若·莫

六大核心虚词

之
代词：他/她/它 → 策之不以其道代物
助词：的 → 小大之狱，虽不能察
助词：主谓间取消独立性 → 甚矣，汝之不惠
动词：往/到 → 之次所旁丛祠中
其
代词：他/他的 → 食其俸禄第三人称
代词：自己的 → 退则思之，其后发反身
指示：那个/这 → 其一犬坐于前远指
语气：表揣测/反问/命令
而
并列：又 → 温故而知新不翻译
转折：但是/却 → 人不知而不愠
递进>：而且 → 登高而招，见者远
修饰：……地 → 默而识之不翻译
因果：于是/就 → 三顾臣于草庐之中
于
介词：在 → 战于长勺处所
介词：对/向 → 贫者语于富者对象
介词：比 → 苛政猛于虎比较
介词：从 → 遂行贩江陵来源
以
介词：用/拿 → 以刀劈狼首工具
介词：凭借 → 以我酌油知之
介词：因为 → 以是人多以书假余
连词：来/以便 → 属予作文以记之目的
为
动词：做/作为 → 为一说，使与书俱
介词：给/替 → 为我击破沛公军
介词：因为 → 始为薪者
语气：呢（疑问） → 何以哉读wéi

💡 考场技巧

虚词题通常是选择题，判断关键看位置：之/其/而/于/以/为是高频六字。看前后搭配（主谓之间/动宾之间/介词后名词）来快速判断用法。
