一、课外文言文的考查特点

课外文言文是南充中考语文的必考题，分值8-10分。与课内文言文不同，课外文言文没有原文可背，考查的是真正的阅读理解能力。

很多同学见到课外文言文就慌，其实课外文言文的考点和课内文言文是一样的，只是换了一篇文章而已。掌握了课内文言文的基础，课外文言文完全能应对。

二、实词推断技巧

1. 课内迁移法（最重要）

课外文言文中的实词，大多是课内学过的词的引申义或假借义。看到生词，先想课内学过的相同汉字的用法。

例如：课外句子中出现"徒"字，想到《送东阳马生序》中学过的"当余之从师也，负箧曳屣行深山巨谷中，穷冬烈风，大雪深数尺，足肤皲裂而不知"——这里的"徒"是"只、仅仅"的意思。

2. 语境推断法

根据上下文推断词义。方法：

  • 看搭配：词语前后常有关联词或解释词
  • 看情感：作者对人物是褒是贬
  • 看结构：主语是什么，宾语是什么

3. 词性分析法

根据词语在句中的位置判断词性，再推断词义。例如：

  • 名词用在动词前，可能是主语，也可能是状语（表方式）
  • 动词后接名词，是动宾关系
  • 副词修饰动词形容词

4. 成语印证法

很多文言实词保留在现代成语中，可以通过成语来推断词义：

  • "赴汤蹈火"中的"汤"是"热水"→ 文言文中"汤"即热水
  • "痛心疾首"中的"疾"是"痛"→ 文言文中"疾"有痛的意思
  • "舍生取义"中的"舍"是"舍弃"→ 文言文中"舍"即舍弃
  • "度日如年"中的"度"是"度过"→ 文言文中"度"即度过

三、常见课外实词汇总

1. 常见文言虚词（课内迁移）

  • 之：他（她、它）/ 的 / 取消句子独立性 / 去、往
  • 其：他的 / 那个 / 难道 / 大概
  • 而：表顺承 / 表转折 / 表修饰
  • 于：在 / 从 / 对 / 比 / 被
  • 以：用 / 因为 / 按照 / 来 / 以致
  • 为：做 / 成为 / 被 / 为了
  • 则：就 / 却是 / 那么
  • 乃：就 / 竟然 / 是
  • 且：并且 / 况且 / 将要
  • 虽：虽然 / 即使

四、句子翻译技巧

翻译标准：信、达、雅

信：准确翻译每个字词，不遗漏不添加

达：语句通顺，符合现代汉语习惯

雅：译文的语言优美（考试中能做到前两条即可）

翻译方法：增、删、调、留、换

📝 翻译五字法：

增：补充省略的主语、宾语

删：删除无意义的发声音词（如"夫"在句首可不译）

调：调整宾语前置、定语后置等语序

留：人名、地名、官职名保留不译

换：古词换今词（如"吾"换"我"，"日"换"天/太阳"）

常见句式翻译要点

  • 判断句：……者，……也 / ……也
  • 宾语前置：调换语序，如"何陋之有"→"有什么简陋的呢"
  • 状语后置：于字短语提前翻译，如"战于城南"→"在城南作战"
  • 省略句：补充省略的成分

五、内容理解与分析

1. 断句技巧

课外文言文有时会考查断句，方法：

  • 找对话标志："曰""云""言"后断开
  • 找句末语气词：也、矣、焉、哉等
  • 找对称结构：字数相近、意思对应的句子断开
  • 找顶真修辞：同一个字连续出现

2. 内容概括

概括文章主要内容，回答"谁+做什么+结果如何"：

  • 看清题目问的是整体还是局部
  • 抓住主要人物和事件
  • 避免细节干扰，提取核心信息

3. 人物形象分析

分析人物形象，从以下角度入手：

  • 直接描写：文中直接描写人物语言、行为、性格的词句
  • 侧面烘托：其他人对人物的评价、与人物相关的事件
  • 矛盾冲突：人物在关键事件中的选择和做法
  • 作者态度：作者对人物是褒是贬（从用词可以看出）

六、答题公式总结

1. 实词解释题

公式：课内迁移 + 语境推断 + 词性验证

答题格式："X字在这里的意思是______，依据是______"

2. 句子翻译题

公式：逐字对应 + 调整语序 + 补充省略 + 流畅表达

答题格式："翻译：______（关键词用圆点标注）"

3. 内容理解题

公式：提取信息 + 概括要点 + 准确表述

答题格式："从文中可以看出，______（什么人/什么事/什么品质/什么道理）"

4. 人物形象题

公式：定位描写 + 提炼特征 + 有理有据

答题格式："我认为X是一个______（性格/品质）的人，从文中______（原文）可以看出。"

5. 启示感悟题

公式：概括道理 + 联系实际 + 适度延伸

答题格式："这个故事告诉我们______（道理），结合实际，我认为______（自己的理解）"

七、南充中考真题示例

2024年南充中考课外文言文

【真题】阅读《歧路亡羊》选段，回答问题。

题目1：解释"亡"字的意思

答案："亡"在这里的意思是"丢失"，依据是课文《塞翁失马》中"马无故亡而入胡"的"亡"也是丢失的意思，可以迁移推断。

题目2：翻译句子

题目："杨子之邻人亡羊，既率其党，又请杨子之竖子追之。"

答案：杨子的邻居丢失了羊，已经带领了他的人（去找），又请杨子的童仆去追（羊）。

题目3：这个故事告诉我们什么道理？

答案：做事要专注方向正确，否则努力也是白费。歧路太多，再怎么努力也找不到目标。

📝 文言文阅读自检清单：

① 常见虚词（之、其、而、于、以、为、则、乃、且、虽）能准确辨析

② 常见实词能通过课内迁移推断

③ 句子翻译掌握增删调留换五法

④ 内容理解会概括主要信息

⑤ 人物形象分析有理有据

⑥ 启示感悟题能联系实际

📌 核心要点回顾

实词推断：课内迁移法是核心，结合语境、词性、成语印证

虚词辨析：注意一词多义，根据语境判断具体用法

翻译技巧：增删调留换，重点处理省略句和倒装句

内容理解：抓住人物和事件，提炼核心信息

人物分析：直接描写+侧面烘托+矛盾冲突三管齐下

启示感悟：概括道理+联系实际，避免空洞口号
