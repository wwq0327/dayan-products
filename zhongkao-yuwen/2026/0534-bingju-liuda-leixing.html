一、病句为什么必考

病句修改是南充中考语言运用部分的固定题型，通常在第II卷第3-4题出现，分值4-6分。病句看似简单，但六种类型各有陷阱，稍不留神就丢分。

解答病句题要两步走：第一步判断类型，第二步正确修改。判断类型是关键——一旦辨认出病句属于哪种类型，修改方法就呼之欲出。

二、类型一：成分残缺

什么是成分残缺

句子中缺少必要的语法成分——主语、谓语、宾语、定语、状语等，导致句子结构不完整。

常见形式

1. 缺主语——一句话说出来不知道"谁"在做这个动作。

❌ 通过这次活动，使我受到深刻教育。
✓ 这次活动，使我受到深刻教育。/ 通过这次活动，我受到深刻教育。

2. 缺谓语——有了主语但没有说明主语"做什么"。

❌ 我们的学校要成为全市示范。
✓ 我们的学校要成为全市示范学校。

3. 缺宾语——有了动词但没有说明"做什么""是什么"。

❌ 同学们决心为建设祖国。
✓ 同学们决心为建设祖国贡献力量。

修改方法

📌 口诀：

成分残缺肿么办？缺啥补啥最应当。

主语残缺查开头，谓语残缺看中间，

宾语残缺找动后，状语残缺附加找。

三、类型二：搭配不当

什么是搭配不当

句子中词语与词语之间的搭配不符合语言习惯或逻辑规律。

常见形式

1. 主谓搭配不当

❌ 我们的学习成绩比前几年增加了很多。
✓ 我们的学习成绩比前几年提高了很多。/ 我们的学习成果比前几年增加了很多。

2. 动宾搭配不当

❌ 我们要珍惜现在的幸福生活，不要浪费时间和金钱。
✓ 我们要珍惜现在的幸福生活，不要浪费时间、虚度光阴。

3. 修饰语与中心语搭配不当

❌ 我们的友谊十分浓厚。
✓ 我们的友谊十分深厚。/ 我们的情谊十分浓厚。

4. 关联词搭配不当

❌ 因为他学习努力，所以成绩优秀。
✓ 因为他学习努力，所以成绩优秀。（正确）

修改方法

📌 口诀：

搭配不当肿么办？词语换用记心上。

主谓动宾要对应，修饰中心细思量。

关联词语查搭配，前后一致不相忘。

四、类型三：语序不当

什么是语序不当

词语的位置排列顺序不符合语言习惯或逻辑规律，导致表达混乱。

常见形式

1. 多层定语语序不当

❌ 这是一位优秀的有三十年教龄的女语文教师。
✓ 这是一位有三十年教龄的优秀的女语文教师。/ 这是一位女语文教师，有三十年教龄，优秀。

2. 多层状语语序不当

❌ 同学们在教室里认真地纷纷讨论着这道题。
✓ 同学们在教室里纷纷认真地讨论着这道题。

3. 句子成分顺序不当

❌ 全班同学只要努力，都能取得好成绩。
✓ 只要全班同学努力，都能取得好成绩。

4. 事理顺序不当

❌ 我们必须一边学习，一边工作。
✓ 我们必须一边工作，一边学习。/ 我们必须先学习，后工作。

多层定语排列顺序口诀

📌 口诀：

定语排列有顺序，范围数词属动名；

代词在前形其次，名词短语最后拎；

口诀：代形数名动名，范围用途和心情。

简记：谁（代词）的什么样的（形）几（数词）什么（名词）怎么样（动词+名词）

五、类型四：重复啰嗦

什么是重复啰嗦

句子中出现了意思相同或相近的词语，造成重复多余；或者词语堆砌，表意拖沓。

常见形式

1. 相同词语重复

❌ 这个问题其实并不是不重要。
✓ 这个问题其实并不重要。

2. 意思相近的词重复

❌ 大家要下定决心，努力刻苦学习。
✓ 大家要下定决心，刻苦学习。/ 大家要努力，刻苦学习。

3. 画蛇添足式重复

❌ 这件事的真正主要原因是因为他粗心大意。
✓ 这件事的主要原因是他粗心大意。/ 这件事是因为他粗心大意。

4. 堆砌词藻

❌ 听了他的先进事迹报告以后，使我内心深处受到了深刻的教育和启发。
✓ 听了他的先进事迹报告，我内心受到深刻教育。

修改方法

📌 口诀：

重复啰嗦肿么办？保留一个去atory。

相近词语取其一，堆砌词藻要精简。

"大约""左右""上下"，三选一则最为佳。

六、类型五：表意不明

什么是表意不明

句子可以有两种或两种以上的理解，让人看不懂到底是哪个意思。

常见形式

1. 词义多义造成歧义

❌ 妈妈给我买了一件衣服，很漂亮。
✓ 妈妈给我买了一件很漂亮的衣服。

2. 指代不明造成歧义

❌ 老师叫小明和小军的爸爸来学校，你和他最好一起去。
✓ 老师叫小明和小军的爸爸来学校，你最好和他们一起去。

3. 停顿位置不同造成歧义

❌ 诗人认为杜甫和李白一样有名。
✓ 诗人认为杜甫和李白一样有名。（李白被认为和杜甫一样有名？）/ 诗人认为杜甫和李白一样有名——这是对两人名气的认同。

修改方法

📌 口诀：

表意不明肿么办？语境补充是关键。

指代要指说清楚，停顿位置要调当。

多项定语加括号，单义表达最应当。

七、类型六：不合逻辑

什么是不合逻辑

句子语法上没有问题，但表达的内容违背了客观规律或日常常识。

常见形式

1. 自相矛盾

❌ 开学以来，他agan的学习态度取得了很大进步。
✓ 开学以来，他端正了学习态度，取得了很大进步。

2. 否定不当

❌ 他不得不承认自己不笨。
✓ 他承认自己不笨。/ 他不得不承认自己很聪明。

3. 范围不当

❌ 所有中学生的知识水平都在不断提高。
✓ 中学生的知识水平都在不断提高。/ 广大中学生的知识水平在不断提高。

4. 主客颠倒

❌ 我对他的热情，把我感动得说不出话来。
✓ 他的热情，把我感动得说不出话来。/ 他的热情让我说不出话来。

修改方法

📌 口诀：

不合逻辑肿么办？常识检验来把关。

否定词要数清楚，双重否定要看全。

因果先后要理顺，主客位置不可反。

八、病句辨析四步法

第一步：紧缩——去掉枝叶，保留主干

拿到句子，先去掉所有修饰成分（定语、状语、补语），找出句子的"主语+谓语+宾语"主干。

例："在我们班级里，那些积极向上的同学们，每天都非常认真地学习。"→ 主干："同学们学习。"

第二步：搭配——检查主干词语是否搭配

主语和谓语是否搭配？谓语和宾语是否搭配？

例："我们的学习成绩增加了很多。"→ 主干："成绩增加"——主谓搭配不当，应改为"成绩提高"。

第三步：分析——判断病句属于六种类型中的哪一种

  • 主干完整但意思不对 → 不合逻辑
  • 主干有残缺 → 成分残缺
  • 主干没问题，附加语位置不对 → 语序不当
  • 词义重复或堆砌 → 重复啰嗦
  • 有多种理解方式 → 表意不明

第四步：修改——对症下药

📌 修改原则：

增（成分残缺要增补）、删（重复啰嗦要删除）、换（搭配不当要替换）、调（语序不当要调整）

口诀："增删换调"四字法，对症下药效果佳。

九、经典错题解析

【2023年南充中考第3题】

❌ 下列句子没有语病的一项是（ ）

A. 通过开展"书香校园"活动，使同学们的阅读兴趣大大增强了。

B. 能否制定合理的学习计划，是提高学习效率的重要途径。

C. 春天的南充，是一个充满生机的季节。

D. 这部小说完美地塑造了一个英雄形象。

✅ 正确答案：A

A：成分残缺（缺主语）→ 去掉"通过"或"使"

B：不合逻辑（两面对一面）→ "能否"是两面，"是提高"是一面，应去掉"能否"

C：不合逻辑（主客颠倒）→ 春天的南充是"地方"不是"季节"，应改为"南充的春天"

D：正确 ✓

十、易错提醒

  • ❌ "通过……使……"是典型的缺主语，看到就要想到成分残缺
  • ❌ "左右""大约""上下"不要重复使用，只留一个
  • ❌ "是否""能否"等两面词后面必须也要有两面词对应，否则不合逻辑
  • ❌ 定语状语位置是高频考点，多层修饰语顺序要记清
  • ❌ 修改病句不能改变句子原意，只能让句子更通顺

📌 病句六类速记口诀

成分残缺肿么办？缺啥补啥最应当。

搭配不当怎么办？词语换用在心上。

语序不当怎么办？调整顺序要妥当。

重复啰嗦怎么办？保留一个去冗长。

表意不明怎么办？语境补充来帮忙。

不合逻辑怎么办？常识检验来应当。

辨析病句四步走：先紧缩，再搭配，三分析，四修改。增删换调，对症下药。
