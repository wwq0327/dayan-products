一、古诗词默写的丢分原因

古诗词默写10分，是中考语文中性价比最高的10分——背了就能拿分，不背就丢分。但很多同学明明背了，却因为写错字而丢分，功亏一篑。

默写丢分主要有三种原因：

  • 字形错误：形近字写错，如"萧"写成"箫"，"雁"写成"雁"
  • 字音错误：同音字写错，如"沧海"写成"仓海"，"青山"写成"青山"
  • 语境错误：不理解诗意写错，如该用动词的地方用了名词

二、字形易错50句

【第1-10句】形近字混淆

《天净沙·秋思》马致远

枯藤老树昏鸦，老股 → 正确答案：老树

小桥流水人家，人家 人家 → 正确

古道西风瘦马，古渡 → 正确答案：古道

《望岳》杜甫

岱宗夫如何？齐鲁青未了。未了写成味了 → 正确：未了

造化钟神秀，阴阳割昏晓。割写成害 → 正确：割

《春望》杜甫

烽火连三月，家书抵万金。峰火写成蜂火 → 正确：烽火

白头搔更短，浑欲不胜簪。浑欲写成浑次 → 正确：浑欲

【第11-20句】同音字混淆

《使至塞上》王维

大漠孤烟直，长河落日圆。大漠写成大莫 → 正确：大漠

长河写成常河 → 正确：长河

《钱塘湖春行》白居易

乱花渐欲迷人眼，浅草才能没马蹄。渐欲写成溅欲 → 正确：渐欲

才能写成才蓝 → 正确：才能

《饮酒·其五》陶渊明

采菊东篱下，悠然见南山。东篱写成东黎 → 正确：东篱

见南山写成望南山 → 正确：见南山（"见"是"出现"的意思）

【第21-30句】难写字错误

《茅屋为秋风所破歌》杜甫

唇焦口燥呼不得，归来倚杖自叹息。唇焦写成唇干 → 正确：唇焦

倚杖写成椅仗 → 正确：倚杖

《琵琶行》白居易

转轴拨弦三两声，未成曲调先有情。转轴写成转轴（同音但错）→ 正确：转轴

拨弦写成拨线 → 正确：拨弦

大弦嘈嘈如急雨，小弦切切如私语。嘈嘈写成操操 → 正确：嘈嘈

《赤壁》杜牧

折戟沉沙铁未销，自将磨洗认前朝。折戟写成折戈 → 正确：折戟

铁未销写成铁未消 → 正确：未销

【第31-40句】理解性默写易错

《登飞来峰》王安石

不畏浮云遮望眼，自缘身在最高层。自缘写成只缘 → 正确：自缘（"只"是错别字，"自"是"自己"）

《登鹳雀楼》王之涣

白日依山尽，黄河入海流。白日写成白月 → 正确：白日

欲穷千里目，更上一层楼。千里目写成千里木 → 正确：目

《题西林壁》苏轼

横看成岭侧成峰，远近高低各不同。各不同写成不相同 → 正确：各不同

不识庐山真面目，只缘身在此山中。只缘写成自缘（和《登飞来峰》混淆）→ 正确：只缘

【第41-50句】综合易错

《游子吟》孟郊

慈母手中线，游子身上衣。手中线写成手中钱 → 正确：手中线

临行密密缝，意恐迟迟归。密密缝写成蜜蜜缝 → 正确：密密

《过零丁洋》文天祥

人生自古谁无死，留取丹心照汗青。汗青写成汗清 → 正确：汗青（史册代称）

《己亥杂诗》龚自珍

落红不是无情物，化作春泥更护花。落红写成落花 → 正确：落红（落花≠落红）

三、理解性默写应对策略

什么是理解性默写

理解性默写不给上句或下句，而是给一个情境或意思描述，让你写出对应的诗句。这是南充中考的常见题型。

两步答题法

  • 第一步：根据情境或描述，确定主题关键词（如"思乡""爱国""坚强"）
  • 第二步：在脑海中搜索含有该关键词的古诗词，写出最贴切的一句

常见情境对应的诗句

📌 情境→诗句对照：

思念家乡："露从今夜白，月是故乡明"（杜甫）/ "春风又绿江南岸，明月何时照我还"（王安石）

坚定志向："人生自古谁无死，留取丹心照汗青"（文天祥）/ "粉骨碎身浑不怕，要留清白在人间"（于谦）

母爱亲情："慈母手中线，游子身上衣"（孟郊）/ "谁言寸草心，报得三春晖"（孟郊）

珍惜时间："少壮不努力，老大徒伤悲"（汉乐府）/ "黑发不知勤学早，白首方悔读书迟"（颜真卿）

乐观面对："长风破浪会有时，直挂云帆济沧海"（李白）/ "山重水复疑无路，柳暗花明又一村"（陆游）

四、默写检查三步法

默写完成后，用这三步检查：

  • 第一步：数一数字数——每句诗有固定字数，不对就要检查
  • 第二步：看关键词——诗眼往往是难写字，这些字一定要写对
  • 第三步：读出来——读不通顺的地方很可能写错字了

五、易错字汇总表

📌 最容易写错的50个字：

萧→箫（箫/萧易混）、雁→燕（雁/燕不分）、沧→仓（沧/仓同音）、暮→墓（暮/墓形近）

蜡→腊（蜡/腊同音）、籍→藉（籍/藉形近）、倚→椅（倚/椅形近）、浑→混（浑/混同音）

簪→替（簪/替形近）、拨→拔（拨/拔形近）、燥→躁（燥/躁同音）、辩→辨（辩/辨/瓣易混）

辩→辨（辨/辩/瓣易混）、萧→啸（萧/啸形近）、暮→幕（暮/幕形近）、渡→度（渡/度同音）

竟→竞（竟/竞形近）、作→做（作/做用法不同）、青→清（青/清/情同音）、园→圆（园/圆同音）

📌 默写满分口诀

先背后写，写完检查，字数要对；

关键词不能错，诗眼更要细划；

形近字区分，同音字核查；

理解性默写，两步定它；

情境关键词，一搜一写。

默写的10分，是中考语文里最不该丢的10分。背书时就要一边背一边写，拿笔把每个易错字写三遍，比单纯念十遍更有效。
