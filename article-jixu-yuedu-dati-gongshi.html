中考语文｜记叙文阅读答题公式完整汇总

记叙文阅读是中考语文试卷中分值最高的题型之一，也是学生最容易失分的板块。记叙文题型灵活多变，但万变不离其宗——掌握核心答题公式，就能以不变应万变。本文系统梳理记叙文阅读所有常见题型的标准答题公式，配以真题示例，帮助考生在考场上快速组织答案，稳稳拿到高分。

一、记叙文六要素

要素内容答题关键词
时间故事发生的具体或大致时间……时、……之后、某年某月
地点故事发生的场景在家里、学校、山村、城市
人物主要人物与次要人物主人公及关系
起因事件的起因或导火索因为……、由于……
经过事件发展的过程先……然后……最后……
结果事件的结果或感悟最终……、于是……

二、标题含义与作用

题型一：标题含义（深层次含义）

公式：表层含义 + 深层含义（情感/象征/哲理）

【答题模板】

  1. 表层含义：标题字面意思，即……
  2. 深层含义：结合文章主题，标题在文中的隐含意义是……

【范例】《背影》标题含义

  • 表层含义：文章描写了父亲的背影。
  • 深层含义：背影象征父亲默默付出、不善言辞的爱，表达了儿子对父亲的思念与感激。

题型二：标题作用

公式：内容主题 + 行文线索 + 写作手法 + 情感表达 + 读者吸引

【答题模板】

  1. 内容主题：点明写作对象/主要内容……
  2. 行文线索：作为线索贯穿全文……
  3. 写作手法：运用了比喻/象征/双关等手法……
  4. 情感表达：表达作者……的情感……
  5. 读者吸引：设置悬念，吸引读者……

三、环境描写作用

题型三：自然环境描写作用

公式：交代背景 + 渲染气氛 + 烘托心情 + 推动情节 + 突出主题

【答题模板】

  1. 交代故事发生的地点、时间、季节、气候等背景；
  2. 渲染……的氛围，奠定……的感情基调；
  3. 烘托人物……的心情/性格/处境；
  4. 为下文……情节作铺垫，推动故事情节发展；
  5. 突出/深化文章……的主题。

【范例】《背影》开头："祖母去世，父亲赋闲，家道中落。"

  • 交代了家庭的悲惨境遇；
  • 渲染了萧索、悲凉的气氛；
  • 烘托了作者内心的悲凉与无奈；
  • 为下文写父亲的背影铺垫。

题型四：社会环境描写作用

公式：交代时代背景 + 揭示社会现实 + 塑造人物性格 + 揭示主题

【答题模板】

  1. 交代故事发生的时代背景、社会环境……
  2. 揭示当时社会的……现状/风气……
  3. 为人物活动提供典型环境，塑造人物性格……
  4. 揭示/深化文章……的主题。

四、人物描写方法及作用

题型五：人物描写方法辨析

描写方法具体内容作用
动作描写跑、跳、推、拉、敲生动形象地表现人物……
语言描写说了什么话（直接引用）表现人物……的性格/情感
神态描写表情变化：皱眉、微笑、严肃反映人物……的内心
外貌描写长相、穿着、身材揭示人物……的身份/处境/性格
心理描写心想、感到、觉得直接揭示人物……的内心
细节描写微小而典型的动作/神态生动刻画人物……的性格
侧面描写通过他人/环境烘托间接表现主要人物……

题型六：人物描写作用答题公式

公式：运用了……（描写方法），生动形象地写出了人物……（特点），表现了人物……（性格/情感/心理）。

【范例】"他耸耸肩，摇摇头，叹了口气。"

  • 运用了动作描写（耸耸肩、摇摇头）和神态描写（叹气）；
  • 生动形象地写出了他无奈、失望的神情；
  • 表现了他面对困难时的无助与沮丧。

五、故事情节概括

题型七：梳理情节（用简洁语言概括）

公式：人物 + 做什么 + 结果怎样

【答题模板】

  • 开端：……（时间/地点）……发生了……
  • 发展：……（经过）……
  • 高潮：……（高潮）……
  • 结局：……（结果）……

【范例】《项链》故事情节概括

  • 开端：路瓦栽夫人向女友借项链参加舞会。
  • 发展：项链在舞会上丢失，她四处寻找。
  • 高潮：她花十年光阴打工还债，买新项链还给女友。
  • 结局：得知丢失的项链是假的，仅值五百法郎。

题型八：段落作用（中间段落）

公式：内容上 + 结构上

【答题模板】

  • 内容上：写了……，表现了……
  • 结构上：承上启下/为下文作铺垫/推动情节发展/与上文形成对比

六、主题概括

题型九：归纳文章中心思想

公式：内容概括 + 情感领悟 + 道理提炼

【答题模板】

  1. 本文记叙了……（主要内容）
  2. 表现了作者……的思想感情（情感）
  3. 揭示了……的生活道理/社会现实（主题）

【范例】《背影》中心归纳

  1. 本文记叙了父亲在火车站为我送行、爬过站台买橘子的情景；
  2. 表现了父子之间深沉、含蓄的亲情；
  3. 表达了亲情是人生中最珍贵的情感这一主题。

七、表达效果与分析

题型十：赏析句子（修辞手法）

公式：修辞手法 + 内容分析 + 情感效果

【答题模板】这句话运用了……（修辞手法），将……比作……（内容），生动形象地写出了……（对象特点），表达了作者……的情感。

【范例】"那雪，就如鹅毛一般，在天空中纷纷扬扬地飘落。"

  • 运用了比喻的修辞手法；
  • 将雪花比作鹅毛，生动形象；
  • 写出了雪之大、环境之冷；
  • 表达了作者对雪的喜爱和对寒冷的烘托。

题型十一：赏析句子（描写方法）

公式：描写方法 + 写出了什么 + 表现了什么

【答题模板】这句话运用了……（描写方法），生动形象地写出了……（具体内容），表现了人物……的性格/情感，或渲染了……的气氛。

题型十二：词语赏析

公式：词义解释 + 语境义 + 情感分析

【答题模板】"……"这个词的本义是……，在文中指……（语境义），写出了……（对象特点），表达了作者……的情感。

八、真题精讲

【2024 南充中考】阅读下面的文章，回答问题。

题目节选自《父亲的背影》一文。问：请分析文中画线句"父亲费力地从月台的一端，走到另一端，然后慢慢弯下腰去"所运用的人物描写方法及作用。

参考答案：

  • 这句话运用了动作描写（"攀""缩""倾"）和细节描写（"微倾""努力"）；
  • 生动形象地写出了父亲爬过站台时的艰难与吃力；
  • 表现了父亲对儿子深沉的爱，以及儿子对父亲的感动与心酸。
