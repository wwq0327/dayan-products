【课外篇 1】

守株待兔

📜 原文

宋人有耕者。田中有株，兔走触株，折颈而死。因释其耒而守株，冀复得兔。兔不可复得，而身为宋国笑。

📝 译文

宋国有个耕地的农民。他的田里有一个树桩，一只兔子奔跑时撞在树桩上，折断脖子死了。这个农民于是放下他的农具而守着树桩，希望再捡到撞死的兔子。兔子是不可能再得到了，而他自己却被宋国人嘲笑。

📖 重点词汇

【耕者】耕种的人，农民。 【株】树桩。 【走】跑，奔跑。 【折颈】折断脖子。 【释】放下。 【耒(lěi)】农具。 【冀】希望。 【身】自己。

🔗 课内外对比

📗 课内关联：《刻舟求剑》"舟已行矣，而剑不行"。
📘 对比点：两篇寓言均通过故事讽刺不知变通的行为。"走"在古文中常作"奔跑"讲（课内《夸父逐日》"夸父与日逐走"），与今义"行走"不同，需重点区分。

📝 理解练习

1. 解释加点的字：兔走触株（ ） 因释其耒而守株（ ） 冀复得兔（ ）

2. 这则寓言告诉我们什么道理？

✅ 参考答案

1. 走：跑，奔跑。 释：放下。 冀：希望。
2. 这则寓言告诉我们：不要死守狭隘经验，不知变通，否则只会一无所获。讽刺了那些只想坐享其成、不劳而获的人。

【课外篇 2】

郑人买履

📜 原文

郑人有欲置履者，先自度其足，而置之其坐。至之市，而忘操之。已得履，乃曰："吾忘持度。"反归取之。及反，市罢，遂不得履。人曰："何不试之以足？"曰："宁信度，无自信也。"

📝 译文

郑国有个想要买鞋的人，先自己量好脚的尺码，把量好的尺码放在了自己的座位上。到了去集市的时候，却忘记带上尺码。已经选好了鞋子，才说："我忘了带尺码。"于是回家去取。等他返回集市的时候，集市已经散了，最终没有买到鞋。有人说："为什么不用脚去试试鞋呢？"他说："我宁可相信尺码，也不相信自己的脚。"

📖 重点词汇

【履(jǔ)】鞋。 【度(duó)】测量，动词。 【坐】同"座"，座位。 【至】到了。 【之】到，往。 【操】携带。 【乃】于是，就。 【及】等到。 【宁】宁可。

🔗 课内外对比

📗 课内关联：《刻舟求剑》"求剑若此，不亦惑乎"。
📘 对比点：两篇均讽刺教条主义。"度"字在课内《陈涉世家》"关中之固，金城千里"中为名词用法（"制度"），此处为动词"测量"，需结合语境区分。

📝 理解练习

1. 解释加点字：先自度其足（ ） 至之市（ ） 宁信度（ ）

2. "宁信度，无自信也"这句话有什么寓意？

✅ 参考答案

1. 度：测量。 之：到，往。 宁：宁可，宁愿。
2. 寓意：讽刺那些过分迷信教条而忽略客观实际的人。提醒人们要学会灵活变通，根据实际情况解决问题，不能生搬硬套，不知变通。

【课外篇 3】

精卫填海

📜 原文

又北二百里，曰发鸠之山，其上多柘木，有鸟焉，其状如乌，文首，白喙，赤足，名曰"精卫"，其鸣自詨。是炎帝之少女，名曰女娃。女娃游于东海，溺而不返，故为精卫，常衔西山之木石，以堙于东海。

📝 译文

再向北走二百里，有一座山叫发鸠山，山上长着很多柘树。山上有一种鸟，形状像乌鸦，头上有花纹，白嘴，红爪，名叫"精卫"，它的叫声像在叫自己的名字。精卫是炎帝的小女儿，名叫女娃。女娃去东海游玩，溺水后没有回来，因此变成了精卫鸟，常常衔着西山的树枝和石块，用来填塞东海。

📖 重点词汇

【发鸠之山】发鸠山。 【状】形状。 【文首】头上有花纹。 【喙(huì)】嘴。 【是】这。 【少女】小女儿。 【溺】溺水，淹没。 【堙(yīn)】填塞。

🔗 课内外对比

📗 课内关联：精卫填海为课内《山海经》原文，可对比《夸父逐日》学习神话寓言类文言文。
📘 对比点：课内《夸父逐日》"与日逐走"，《精卫填海》"常衔西山之木石"，两篇均表现古代人民不畏艰难、顽强不屈的精神，可作为作文素材积累。

📝 理解练习

1. 解释加点字：其状如乌（ ） 是炎帝之少女（ ） 以堙于东海（ ）

2. 这个故事体现了精卫什么精神？请谈谈你的感悟。

✅ 参考答案

1. 状：形状。 是：这。 以：用，来。
2. 精神：顽强不屈、坚持不懈的精神。感悟：面对无法改变的灾难，精卫不以己悲，而是用一点一滴的行动去抗争。这种明知不可为而为之的勇气，值得我们学习。在学习和生活中，我们也会遇到看似无法完成的任务，但只要有精卫那样的坚持精神，终会有所成就。

【课外篇 4】

孟母断机

📜 原文

孟子之少时，嬉游为贾人炫技之事。孟母渐之愧之，弗听。业断其机杼而叹曰："子之废学，若吾断斯织也。"孟子惧，即前日讲学设席之间，不敢复言学。

📝 译文

孟子小时候，一次玩耍时做了商贩炫耀技艺的事情。孟母觉得这样不好，便带他离开，孟母没有听。孟母于是折断了织布机上的梭子，叹气说："你荒废学业，就像我折断这织布机上的丝线一样。"孟子感到害怕，立即去拜见老师听课，从此不敢再说放弃学习的话。

📖 重点词汇

【少时】小时候。 【嬉游】玩耍。 【贾人】商人。 【炫技】炫耀技艺。 【渐之愧之】觉得这样不好。 【业】于是。 【机杼(zhù)】织布机上的梭子。 【废学】荒废学业。 【斯】这。 【惧】害怕。 【复】再，又。

🔗 课内外对比

📗 课内关联：《孟母断机》与课内《虽有嘉肴》"虽有至道，弗学，不知其善也"都强调了学习的重要性。
📘 对比点：孟母用"断机"类比"废学"，是比喻说理；课内《学弈》通过专心vs三心二意的对比来说明专心致志的重要性，两种论证方法均可作为议论文写作素材。

📝 理解练习

1. 解释加点字：孟母渐之愧之（ ） 业断其机杼（ ） 若吾断斯织也（ ）

2. 孟母用什么方法教育孟子？这个故事说明了什么道理？

✅ 参考答案

1. 渐：觉得不好。 业：于是，就。 斯：这。
2. 方法：孟母用折断织布机梭子来比喻荒废学业，形象直观地教育孟子。道理：学习不可半途而废，持之以恒方能有所成就；同时说明了环境对学习和成长的重要影响。

【课外篇 5】

伯牙绝弦

📜 原文

伯牙鼓琴，钟子期听之。方鼓琴而志在泰山，钟子期曰："善哉！峨峨兮若泰山。"志在流水，钟子期曰："善哉！洋洋兮若江河。"伯牙所念，钟子期必得之。子期死，伯牙谓世再无知音，乃破琴绝弦，终身不复鼓。

📝 译文

伯牙弹琴，钟子期在一旁听他弹奏。伯牙正弹奏时心中想到泰山，钟子期说："真好！巍峨的样子像泰山。"心中想到流水，钟子期说："真好！宽广的样子像江河。"伯牙心中所想的，钟子期必定能够领会。钟子期死后，伯牙认为世间再也没有知音了，于是摔破琴弦，终生不再弹琴。

📖 重点词汇

【鼓】弹奏。 【志】志趣，心中的想法。 【洋洋】宽广的样子。 【所念】心中所想的。 【必得之】必定能够领会。 【谓】认为。 【知音】真正了解自己的人。 【破琴绝弦】摔破琴弦。 【复】再，又。

🔗 课内外对比

📗 课内关联：《伯牙绝弦》为课内古文，可对比《核舟记》"嘻，技亦灵怪矣哉"学习古代关于技艺与知音的表达。
📘 对比点："善哉"在课内《伯牙绝弦》中作"真好"讲，与《卖油翁》"康肃笑而遣之"中的"而"字表修饰作用相同，需掌握"而"字的多种用法。

📝 理解练习

1. 解释加点字：方鼓琴而志在泰山（ ） 洋洋兮若江河（ ） 终身不复鼓（ ）

2. "知音"在文中的含义是什么？伯牙为什么"破琴绝弦"？

✅ 参考答案

1. 方：正，正在。 洋洋：宽广的样子。 复：再，又。
2. 含义：真正了解、懂得自己的人。 原因：钟子期是唯一能听懂伯牙琴音的人，子期死后，伯牙认为世上再无人能听懂他的音乐，因此摔琴绝弦，以谢知音。

【课外篇 6】

截竿入城

📜 原文

鲁有执长竿入城门者，初竖执之，不可；横执之，亦不可。时名士设教，必有以也。或有计之者，曰："何不锯去一端而献之？不然，则子不得前矣。"执竿者闻之，即依言而锯之。

📝 译文

鲁国有个拿着长竿子进城的人，起初竖着拿长竿，进不了城门；又横着拿，也进不了城。当时有个名士教导说："做人必须有一定的办法。"有个给他出主意的人说："为什么不把长竿锯断一端再献上去呢？不这样，你就进不了城了。"拿长竿的人听了他的话，就照他说的把长竿锯断了。

📖 重点词汇

【执】拿，持。 【入城】进城。 【竖】竖着。 【横】横着。 【设教】教导。 【必有以】一定有什么办法。 【或】有人。 【计之者】给他出主意的人。 【不然】不这样。 【依言】照他的话。

🔗 课内外对比

📗 课内关联：此篇与《刻舟求剑》《郑人买履》同为寓言故事，均讽刺不懂变通的人。
📘 对比点：出主意的人看似"好心"，实则让简单问题复杂化；与课内《智子疑邻》"其邻之父"提建议的出发点相似，要注意区分善意建议与无知建议。

📝 理解练习

1. 解释加点字：初竖执之（ ） 横执之（ ） 必有以也（ ）

2. 你认为出主意的人的建议合理吗？为什么？

✅ 参考答案

1. 竖：竖着。 横：横着。 以：办法。
2. 不合理。理由：①建议把竿锯断是一种破坏性的"变通"，实际上把竿竖起来就能进城（只要改变角度或稍微倾斜）；②真正的"变通"是要用最小的代价解决问题，而不是把问题变得更糟；③讽刺了那些自作聪明、把简单问题复杂化的人。

【课外篇 7】

铁杵成针

📜 原文

磨针溪，在眉州眉山县之西南。中有铁杵，像娣娟之针，锐利无比，相传为李太白读书于此所用。问之，则曰："铁杵成针，工夫未深，但只要工夫深，铁杵也能磨成针。"此正所谓："世上无难事，只怕有心人。"

📝 译文

磨针溪，在眉州眉山县的西南方向。溪中有根铁杵，像娣娟的针那样锋利，相传是李白在这里读书时所用的工具。有人问他（这段故事的出处），就说："铁杵成针，工夫不到家，只要工夫下得深，铁杵也能磨成针。"这正是人们所说的："世上无难事，只怕有心人。"

📖 重点词汇

【磨针溪】地名。 【眉山县】地名。 【西南】西南方向。 【铁杵(chǔ)】铁棒。 【娣娟】传说中的仙女。 【相传】民间传说。 【为】被。 【工夫】时间，功夫。 【未深】不到家，不够深。

🔗 课内外对比

📗 课内关联：李白相关课内篇目《闻王昌龄左迁龙标遥有此寄》《行路难》。
📘 对比点：本文与《夸父逐日》《精卫填海》同样体现了坚持精神。"但只要工夫深，铁杵也能磨成针"与《论语》"学而不厌"的精神一脉相承，可作为中考作文"坚持"主题的经典素材。

📝 理解练习

1. 解释加点字：相传为李太白读书于此所用（ ） 工夫未深（ ）

2. 这个故事告诉我们什么道理？请联系实际谈谈。

✅ 参考答案

1. 为：被。 工夫：功夫，时间。
2. 道理：只要有恒心、有毅力，再困难的事也能成功。联系实际：我们在学习中也会遇到难题，如数学的几何证明、语文的作文写作等，一开始可能觉得很难，但只要坚持不懈、反复练习，就一定能攻克难关。这就是"铁杵成针"的精神。

【课外篇 8】

杨氏之子

📜 原文

梁国杨氏子九岁，甚聪惠。孔君平诣其父，父不在，乃呼儿出。为设果，果有杨梅。孔指以示儿曰："此是君家果。"儿应声答曰："未闻孔雀是夫子家禽。"

📝 译文

梁国有一户姓杨的人家，他有个儿子九岁，非常聪明。孔君平去拜访他的父亲，父亲不在家，于是把杨氏子叫出来接待。杨氏子为孔君平摆出水果，水果中有杨梅。孔君平指着杨梅给杨氏子看，说："这是你家的水果。"杨氏子马上回答："没有听说过孔雀是您家的鸟啊。"

📖 重点词汇

【梁国】古代国名。 【甚】很，非常。 【聪惠】聪明。惠同"慧"。 【诣】拜访。 【乃】于是，就。 【为设果】为他摆出水果。 【示儿】给杨氏子看。 【应声答曰】马上回答。 【未闻】没有听说。 【夫子】对年长者的尊称，这里指孔君平。

🔗 课内外对比

📗 课内关联：本文为课内篇目，源自《世说新语》。可对比《陈太丘与友期》学习《世说新语》中的聪慧少年形象。
📘 对比点：杨氏子用"孔雀"对应"杨梅"，与《陈太丘与友期》中元方"入门不顾"同样体现了机敏与智慧。"未闻……"是谦逊的否定式回答，体现言语礼仪之美。

📝 理解练习

1. 解释加点字：甚聪惠（ ） 未闻孔雀是夫子家禽（ ）

2. 杨氏子的回答妙在哪里？试分析。

✅ 参考答案

1. 惠：同"慧"，聪明。 未闻：没有听说。
2. 妙在：①以类相拟，孔君平以"杨梅"调侃"杨氏"，杨氏子则以"孔雀"回应"孔君平"，思路一致却反将一军；②语气谦逊，"未闻"二字既否定了对方的说法，又不失礼貌；③体现了言语的机智与敏捷，是日常交际中快速反应的典范。

【课外篇 9】

塞翁失马

📜 原文

近塞上之人，有善术者，马无故亡而入胡。人皆吊之，其父曰："此何遽不为福乎？"居数月，其马将胡骏马而归。人皆贺之，其父曰："此何遽不能为祸乎？"家富良马，其子好骑，堕而折其髀。人皆吊之，其父曰："此何遽不为福乎？"居一年，胡人大入塞，丁壮者引弦而战。近塞之人，死者十九。此独以跛之故，父子相保。

📝 译文

靠近边塞的人中，有一个擅长道术的人，他家的马无缘无故跑到胡人那里去了。人们都来安慰他，他父亲却说："这怎么就不是福气呢？"过了几个月，那匹马带着胡人的好马回来了。人们都来祝贺，他父亲却说："这怎么就不能是祸患呢？"家里有好马，儿子喜欢骑马，结果从马上摔下来摔断了大腿。人们都来安慰，他父亲又说："这怎么就不是福气呢？"过了一年，胡人大举入侵边塞，成年人都拿起武器去作战。靠近边塞的人，十个有九个都战死了。他的儿子唯独因为腿瘸的缘故，父子两人都保全了性命。

📖 重点词汇

【塞上】边境地区。 【善术者】擅长道术的人。 【亡】逃跑。 【胡】古代对北方民族的称呼。 【吊】安慰。 【何遽】怎么就。 【居】过了。 【将】带着。 【好骑】喜欢骑马。 【堕】摔下。 【髀(bì)】大腿骨。 【丁壮】成年人。 【引弦】拿起武器。 【十九】十个里九个。

🔗 课内外对比

📗 课内关联：此篇为课内篇目，与《智子疑邻》都说明了看待事物要全面，不能只看表面。
📘 对比点：两篇都体现了"祸福相依"的辩证思想。《智子疑邻》从"防盗"角度说事，本文从"祸福转化"角度说理，可作为议论文中"辩证思维"论点的素材。

📝 理解练习

1. 解释加点字：马无故亡而入胡（ ） 此何遽不为福乎（ ） 死者十九（ ）

2. 这个故事揭示了什么道理？请谈谈你的理解。

✅ 参考答案

1. 亡：逃跑。 何遽：怎么就。 十九：十个里有九个（大多数）。
2. 道理：①祸福相依，在一定条件下可以相互转化；②看问题要全面，不能只看到事物的表面；③要用发展和辩证的眼光看待人和事。这个故事启示我们：遇到挫折不要灰心，遇到好事也不要得意忘形，保持平和的心态，才能从容面对人生的起伏。

【课外篇 10】

外科医生

📜 原文

有医者，自称善外科。有一兵阵中箭者，急请视之。乃云可治，即下铁石其疮口，寻又施针，兵惊，忍痛以待。卒问其法，医者摇手曰："仆本治外，疮口之内，仆不能到，此内外科之说也。"

📝 译文

有一个医生，自称擅长外科。有一个士兵在战场上中了箭，急忙请他来看。医生说可以治，于是就在伤口上敷上铁石，又施了针，士兵惊慌，忍着疼痛等待治疗。最后士兵问起治疗方法，医生摇手说："我本来只治外科，伤口里面，我够不到，这就是内科外科的分科说法啊。"

📖 重点词汇

【自称】自己声称。 【善】擅长。 【外科】古代分科名。 【阵中箭】在战场上中了箭。 【请视之】请他来看。 【乃】于是。 【下铁石】敷上铁石（止血）。 【施针】用针治疗。 【寻】随即，接着。 【卒】最后。 【仆】我，谦称。 【内外科之说】内外科各有分工的说法。

🔗 课内外对比

📗 课内关联：讽刺寓言类，与《守株待兔》《郑人买履》同类，讽刺缺乏职业道德或名不副实的现象。
📘 对比点：这个医生的可笑之处在于：事前承诺"可治"，事后推卸责任"不能到"，属于言行不一。类似《卖油翁》中"我亦无他，惟手熟尔"的老翁，这位医生却是"无他术，却冒称善外科"，性质截然不同。

📝 理解练习

1. 解释加点字：自称善外科（ ） 寻又施针（ ） 卒问其法（ ）

2. 这个故事讽刺了什么现象？对我们有什么启示？

✅ 参考答案

1. 善：擅长。 寻：随即，接着。 卒：最后。
2. 讽刺了：①名不副实、夸夸其谈的人；②只图名利、不负责任的工作态度。启示：①做人要诚实守信，说到做到；②面对困难要学会自己寻求真正的解决办法，不能轻信吹嘘；③学习上也一样，不能只听宣传，要看实际能力。

【课外篇 11】

富人为学

📜 原文

富人之子，颇知书。一日，有客过访，适父不在，其子见客，礼甚恭。客问其所学，子曰："《论语》《孟子》皆已卒業。"客曰："《论语》《孟子》，吾虽未竟读，亦尝闻其义。今有一问，子能答之乎？"其子肃然曰："愿请教。"

📝 译文

有个富人的儿子，读过不少书。有一天，有客人来访，正好父亲不在，富人的儿子见了客人，对客人礼节很恭敬。客人问他所学的功课，儿子说："《论语》《孟子》都已经学完了。"客人说："《论语》《孟子》，我虽然没有读完，但也曾经了解过它们的大意。现在有一个问题，你能回答吗？"那儿子肃然起敬地说："愿意请教。"

📖 重点词汇

【过访】来访，拜访。 【适】正好，恰好。 【礼甚恭】礼节很恭敬。 【卒業】完成学业，即学完了。 【虽未竟读】虽然没有全部读完。 【尝】曾经。 【闻其义】了解其大意。 【肃然】肃然起敬的样子。 【愿】愿意。

🔗 课内外对比

📗 课内关联：《伤仲永》强调了后天学习的重要性，与本文"知书"却未必真懂形成对比。
📘 对比点：富人之子自称学完了《论语》《孟子》，却不知道客人会问什么问题，这种"一知半解"与《伤仲永》中方仲永"五岁能诗"却最终"泯然众人"的情况有相通之处——学问需要真正理解，而非流于形式。

📝 理解练习

1. 解释加点字：适父不在（ ） 礼甚恭（ ） 虽未竟读（ ）

2. 富人之子虽然"知书"，但文中有一处细节暴露了他的不足，是哪一处？说明了什么？

✅ 参考答案

1. 适：正好，恰好。 甚：很。 虽：虽然。 竟：全部。
2. 暴露不足的细节是：客人说"今有一问，子能答之乎？"时，儿子"肃然"作答，说明他对客人接下来要问什么毫无准备，只能"愿请教"。说明：真正有学问的人不会在不知对方问题的情况下贸然答应，这反映了富人之子只是形式上"知书"，并未真正理解和应用所学知识。

【课外篇 12】

东施效颦

📜 原文

西施病心，皱眉而观者，其里之丑人见而美之，归亦捧心而颦其眉。里之富人见之，闭门而不出；贫者见之，挈妻子而去之走。彼知颦美，而不知颦之所以美。

📝 译文

西施心口痛，皱着眉头看着乡亲们，她家乡的一个丑女人看见了，觉得她这样很美，回去后也捂着心口皱着眉头。乡里的富人看见了，紧闭大门不出来；穷人看见了，带着妻子儿女走开。那个丑女人只知道皱着眉头美，却不知道皱眉头美的原因。

📖 重点词汇

【病心】心口痛。 【皱眉】皱着眉头。 【里】乡里，家乡。 【丑人】丑女人。 【美之】觉得她美。 【归】回去。 【捧心】捂着心口。 【颦(pín)】皱眉。 【挈(qiè)】带着。 【妻子】妻子和儿女。 【去之走】离开跑掉。 【所以】……的原因。

🔗 课内外对比

📗 课内关联：课内《买椟还珠》讽刺取舍不当，与本文均通过寓言说明深层道理。
📘 对比点：东施只知道"颦眉"的外在形式，不知道西施颦眉是因为"病心"这一内在原因，属于只模仿形式不探究本质。与《揠苗助长》都是违反事物规律、一味模仿导致失败的典型案例。

📝 理解练习

1. 解释加点字：其里之丑人见而美之（ ） 挈妻子而去之走（ ） 所以美（ ）

2. 这则寓言说明了一个什么道理？请结合实际谈谈。

✅ 参考答案

1. 美：觉得美，以……为美。 去之走：离开走掉。 所以：……的原因。
2. 道理：盲目模仿而不理解本质，不仅不能达到目的，反而会适得其反。联系实际：学习中有些同学看到学霸的学习方法就去照搬，却不了解学霸方法背后的学习习惯和思维模式，结果邯郸学步，自己的方法也丢了。学习要结合自身实际，借鉴他人经验时，要理解其本质和规律。

【课外篇 13】

乘风破浪

📜 原文

宗悫，字义干，南阳涅阳人。叔父炳，高尚不仕。悫年少时，炳问其志，悫曰："愿乘长风，破万里浪。"炳甚异之。曰："汝大用吾不能论，富贵之日，无相忘也。"

📝 译文

宗悫，字义干，南阳涅阳人。他的叔父宗炳，志向高尚不出来做官。宗悫年少时，宗炳问他的志向，宗悫说："我希望驾着长风，渡过万里巨浪。"宗炳非常诧异，说："你将来会得到大重用，我不能给你下定论，但将来你富贵的时候，不要忘记了我。"

📖 重点词汇

【宗悫(què)】人名。 【南阳涅阳】地名。 【叔父】父亲的弟弟。 【炳】宗炳，叔父的名字。 【高尚不仕】志向高尚不出来做官。 【年少】年轻时候。 【志】志向。 【乘长风】驾着长风。 【破万里浪】渡过万里巨浪。 【甚异之】非常诧异。 【大用】重用。 【无相忘】不要忘记了我。

🔗 课内外对比

📗 课内关联：本文与《夸父逐日》《愚公移山》同样体现了远大志向与积极进取的精神。
📘 对比点："乘风破浪"现已成为成语，比喻志向远大、不畏艰险、勇往直前。"愿乘长风，破万里浪"与《论语》"士不可以不弘毅，任重而道远"的精神内核相通，是中考作文"志向"主题的经典素材。

📝 理解练习

1. 解释加点字：愿乘长风（ ） 破万里浪（ ） 甚异之（ ）

2. 宗悫的志向给你什么启发？

✅ 参考答案

1. 乘：驾着。 破：冲破，渡过。 异：认为……奇异（感到诧异）。
2. 启发：①人要有远大的志向，少年的宗悫就立下了"乘风破浪"的宏愿，这种志存高远的精神是我们学习的榜样；②理想是人生的灯塔，有理想才有前进的动力；③在实现理想的道路上会遇到困难，但只要坚持不懈，终能"破万里浪"。作为中学生，我们也要树立远大理想，并为之努力奋斗。

【课外篇 14】

叶公好龙

📜 原文

叶公子高好龙，钩以写龙，凿以写龙，屋室雕文以写龙。于是天龙闻而下之，窥头于牖，施尾于堂。叶公见之，弃而还走，失其魂魄，五色无主。是叶公非好龙也，好夫似龙而非龙者也。

📝 译文

叶公子高非常喜欢龙，用钩子画龙，用凿子刻龙，房屋卧室等处都雕刻上龙的花纹来装饰龙。于是天上的真龙听说了，就从天上降下来，把头探到窗户里，尾巴拖到厅堂上。叶公看见真龙后，转身就跑，吓得失魂落魄，脸色大变。叶公并不是真的喜欢龙啊，他喜欢的只是那些像龙却不是龙的东西罢了。

📖 重点词汇

【叶公】姓叶，字子高。 【好(hào)】非常喜欢。 【钩以写龙】用钩子画龙。写：画。 【凿】凿子。 【雕文】雕刻的花纹。 【闻】听说。 【下之】降下来。 【窥头于牖(yǒu)】把头探到窗户。 【施尾于堂】把尾巴拖到厅堂。 【弃而还走】转身就跑。 【失其魂魄】吓得失魂落魄。 【五色无主】脸色大变，没有主见。 【似龙而非龙】像龙却不是龙。

🔗 课内外对比

📗 课内关联：本文为课内篇目，属寓言成语类，与《守株待兔》《买椟还珠》同类，说明表面与实质的差异。
📘 对比点：叶公好龙的可笑之处在于他喜欢的只是"似龙而非龙"的形式，而非真龙本身。这与《邹忌讽齐王纳谏》中邹忌通过自身经历说明"王之蔽甚矣"的类比思维相对，需要辨清"喜欢形式"与"喜欢实质"的区别。

📝 理解练习

1. 解释加点字：叶公子高好龙（ ） 窥头于牖（ ） 是叶公非好龙也（ ）

2. "叶公好龙"这个成语用来比喻什么？试举例说明。

✅ 参考答案

1. 好：喜欢。 窥：探。 是：这。
2. 比喻：表面上喜欢某样东西，实际上并非真正喜欢，甚至畏惧或回避。举例：①有些人嘴上说重视教育，却从不花时间陪伴孩子学习，是教育上的"叶公好龙"；②有些人口头上说要减肥，却抵挡不住美食诱惑，是减肥中的"叶公好龙"。提醒我们要言行一致，真正喜欢就要付诸行动。

【课外篇 15】

愚公移山（原文节选·课内关联）

📜 原文

北山愚公者，年且九十，面山而居。惩山北之塞，出入之迂也。聚室而谋曰："吾与汝毕力平险，指通豫南，达于汉阴，可乎？"杂然相许。其妻献疑曰："以君之力，曾不能损魁父之丘，如太行、王屋何？且焉置土石？"杂曰："投诸渤海之尾，隐土之北。"遂率子孙荷担者三夫，叩石垦壤，箕畚运于渤海之尾。

📝 译文

北山愚公，年纪将近九十岁，面对着山居住。他苦于山北道路阻塞，进出都要绕远路。于是召集全家人商量说："我和你们尽全力削平这座险峻的高山，使道路直通豫州南部，到达汉水南岸，可以吗？"大家纷纷表示赞同。他的妻子提出疑问说："凭你的力量，连魁父这样的小山都削不平，又能拿太行山、王屋山怎么样呢？况且往哪里放置土石呢？"大家纷纷说："把土石扔到渤海的边上，隐土的北边。"于是愚公率领三个能挑担子的子孙，凿石挖土，用簸箕担运到渤海边上。

📖 重点词汇

【年且九十】年纪将近九十。 【面山而居】面对山居住。 【惩】苦于。 【塞】阻塞。 【迂】绕远路。 【聚室而谋】召集全家人商量。 【毕力平险】尽全力削平险峻。 【指通豫南】直通豫州南部。 【杂然相许】纷纷表示赞同。 【献疑】提出疑问。 【曾不能】连……都不能。 【且焉置土石】况且往哪里放置土石。 【荷担】挑担子。 【叩石垦壤】凿石挖土。 【箕畚】簸箕。

🔗 课内外对比

📗 课内关联：本篇为课内重点篇目，可对比《精卫填海》《夸父逐日》学习古代寓言中的抗争精神。
📘 对比点：三篇均体现了不畏艰难、坚持不懈的精神，但各有侧重：精卫填海重在"不屈"，夸父逐日重在"追求"，愚公移山重在"坚持"。可作为作文素材综合使用，丰富文章层次。

📝 理解练习

1. 解释加点字：年且九十（ ） 聚室而谋（ ） 叩石垦壤（ ）

2. 愚公移山成功的原因是什么？这给你什么启示？

✅ 参考答案

1. 且：将要，快要。 聚室：召集全家。 叩：敲，凿。
2. 原因：①有明确的目标——"指通豫南，达于汉阴"；②有坚定的信念——面对妻子和智叟的质疑，不为所动；③有持之以恒的行动——子孙后代一起努力；④方法可行——"投诸渤海之尾"。启示：无论学习还是生活，目标明确、坚持不懈、善于借助他人力量，是成功的重要因素。

第二部分：中考文言文高频词汇表（50词）

以下50个词汇为中考文言文常见考查对象，涵盖虚词（如"之""于""而""以"）和实词（如"穷""奇""故"），建议结合上下文理解记忆。

📘 一、常见虚词（20个）

词汇 常见释义 课内示例 语境理解
之 的 / 取消主谓独立性 / 代词 / 到、往 《岳阳楼记》"前人之述备矣"（的）
《学弈》"弈秋，通国之善弈者也"（的）
《两小儿辩日》"孔子东游"（到，往）		 作助词"的"时最常见；作动词"到"时常与"之"后的地点名词搭配
于 在 / 向 / 从 / 对 / 比 《生于忧患》"故天将降大任于斯人"（给）
《爱莲说》"香远益清"（助词，无实义）		 "于"字后常跟地点或对象，是判断"于"字用法的关键
而 表顺承 / 表转折 / 表修饰 / 表并列 《送东阳马生序》"言和而色夷"（并列，和）
《刻舟求剑》"舟已行矣，而剑不行"（转折，却）		 关键是看前后分句的关系：顺接用"就"，转接用"却"，无明显关系则表修饰
以 用 / 以为 / 因为 / 以致 / 凭借 《岳阳楼记》"不以物喜"（因为）
《矛与盾》"以子之矛，攻子之盾"（用）		 "以"后为名词时多解为"用"；后为情感词时多解为"因为"
其 他的 / 那个 / 难道 / 加强语气 《伤仲永》"父利其然也"（他的）
《马说》"其真无马邪"（难道）		 代人时指"他的/她的"，代事时指"那件"
乃 于是 / 才 / 竟然 / 你 《出师表》"乃不知有汉"（竟然）
《陈涉世家》"陈胜乃立为王"（于是）		 出现在句首时常表结果或轻微转折
虽 虽然 / 即使 《马说》"故虽有名马"（即使）
《曹刿论战》"虽不能察"（虽然）		 后文有"然"则解"虽然"；后文有假设则解"即使"
然 但是 / ……的样子 / 这样 《伤仲永》"父利其然也"（这样）
《口技》"忽然抚尺一下"（……的样子）		 作连词时表转折；作形容词词尾时解"……的样子"
何 什么 / 为什么 / 怎么 《曹刿论战》"肉食者谋之，何间焉"（为什么）
《愚公移山》"如太行、王屋何"（拿……怎么办）		 出现在句首或句末，问原因、目的或反问
焉 哪里 / 于是 / 语气词 《愚公移山》"且焉置土石"（哪里）
《醉翁亭记》"然后有憾"（无实义，语气词）		 句末常见，疑问句中解"哪里"；无义时为纯语气词
为 做 / 被 / 因为 / 为了 / 是 《伤仲永》"其诗以养父母"（为了）
《卖油翁》"为一鸡"（被）		 "为"后有动词时解"为了"；"为"前有施事者时解"被"
也 语气词：判断/解释/感叹 《伤仲永》"金溪民方仲永"（无实义，判断语气）
《爱莲说》"可远观而不可亵玩焉"（感叹）		 出现在句末，常表判断或感叹，读时需读出语调
者 ……的人 / ……的事 / 停顿 《伤仲永》"邑人奇之"（这件事）
《陈涉世家》"陈胜者，阳城人也"（……的人）		 常与"也"搭配，构成"……者，……也"的判断句式
矣 了 / 啊 《刻舟求剑》"舟已行矣"（了）
《欧阳修》"事理通达"（语气词）		 表陈述或感叹，有强调作用
哉 啊 / 呢（表感叹或反问） 《醉翁亭记》"太守乐其乐"（啊）
《爱莲说》"可爱者甚蕃"（无实义）		 常与"何""岂"搭配表反问
夫 大丈夫 / 那个 / 语气词 《愚公移山》"遂率子孙荷担者三夫"（人）
《口技》"余闻之也久"（无实义）		 作量词时指成年男子
若 好像 / 如果 / 你 《夸父逐日》"若"（好像）
《出师表》"若印毕"（如果）		 作"如果"时多出现在条件句中
是 这 / 判断词 《伤仲永》"父利其然也"（这）
《爱莲说》"斯是陋室"（判断词）		 古文中"是"多为指示代词"这"，作判断词是后来发展
故 所以 / 故意 / 缘故 / 旧有的 《曹刿论战》"故君子有不战"（所以）
《出师表》"故临崩寄臣以大事"（所以）		 出现在因果句中常解为"所以"
即 立即 / 就是 / 如果 《陈涉世家》"项燕为楚将，数有功"（就是）
《卖油翁》"即公休"（就）		 作"立即"时修饰动词，作"就是"时表判断

📙 二、常见实词（30个）

词汇 常见释义 课内示例 记忆提示
走跑，奔跑《夸父逐日》"夸父与日逐走"（跑）
《守株待兔》"兔走触株"（跑）		古义"跑"，今义"行走"，需重点区分
穷穷尽 / 困窘 / 贫穷《送东阳马生序》"穷冬烈风"（深）
《曹刿论战》"穷寇勿追"（穷尽）		形容困境时解"困窘"；形容季节时解"深"
奇奇怪的 / 奇妙 / 以……为奇《伤仲永》"邑人奇之"（以……为奇）
《核舟记》"明有奇巧人"（奇妙）		作动词时后接"之"，解"以……为奇"
病疾病 / 生病 / 困苦《得道多助》"然后知生于忧患"（疾病）
《卖油翁》"康肃公问其故"（疾病）		古文常解"困苦"；现代解"疾病"
汤热水 / 菜汤《孟子》"汤名"（热水）
今义"菜汤"		古义"热水"，如"赴汤蹈火"
去离开 / 去掉 / 距《桃花源记》"不复得路，遂迷"（离开）
《出师表》"去而"（离开）		古义多"离开"，今义多"到某地去"
鄙见识浅薄 / 看不起 / 边境《曹刿论战》"肉食者鄙"（见识浅薄）
《左传》"蜀之鄙"（边境）		作形容词时解"浅薄"
狱案件 / 监狱《曹刿论战》"小大之狱"（案件）古义"案件"，今义"监狱"
再第二次 / 两次《狼》"再投之"（第二次）
《陈涉世家》"田者为再"（两次）		古义"第二次"，今义"又"
涕眼泪（古）；鼻涕（今）《出师表》"临表涕零"（眼泪）古义"眼泪"，今义"鼻涕"
穷穷尽 / 走到尽头《桃花源记》"欲穷其林"（走到尽头）
《醉翁亭记》"乐亦无穷"（穷尽）		"穷"和"尽"在古文中常互训
谢道歉 / 感谢 / 谢绝《送东阳马生序》"捧手而不谢"（道歉）
《孔雀东南飞》"谢新手下人"（谢绝）		结合语境判断具体含义
观看 / 观赏 / 景观《岳阳楼记》"迁客骚人，多会于此"（看）
《三峡》"每至晴初霜旦"（观赏）		作动词解"看"，作名词解"景观"
将将要 / 将领 / 带领《出师表》"将荆州之军"（带领）
《凉州词》"春风不度玉门关"（将要）		作动词时解"带领"；作副词时解"将要"
属连接 / 隶属 / 管辖 / 一类《三峡》"属引凄异"（连接）
《陈涉世家》"徒属皆日"（部属）		读zhǔ时解"连接"；读shǔ时解"隶属"
绝断 / 极 / 消失《三峡》"绝巘多生怪柏"（极高）
《核舟记》"钩画了还原"（完全）		作形容词时解"极"
素白色 / 向来 / 空《童区寄传》"素习之"（向来）
《孔雀东南飞》"红妆已复"（白色）		"素"常解"向来、一向"
顾回头看 / 照顾 / 拜访《出师表》"三顾臣于草庐之中"（拜访）
《陈太丘与友期》"入门不顾"（回头看）		"三顾茅庐"是著名典故
诚真的 / 如果真的《得道多助》"此诚危急存亡之秋也"（真的）
《出师表》"诚宜开张圣听"（如果真的）		作副词时解"真的"，常与"若"搭配
复再，又 / 恢复 / 重复《桃花源记》"不复得路"（再）
《出师表》"恢复汉室"（恢复）		作"再"讲时最常见
举举起 / 推举 / 全《陈涉世家》"举大计"（起义）
《岳阳楼记》"万类霜天竞自由"（全）		"举"作"全"讲时常见"举国""举家"
识知道 / 记住 / 标志《石壕吏》"天明登前途，独与老翁别"（知道）
《礼记》"多见而识之"（记住）		读zhì时解"标志"，如"博闻强识"
名名字 / 名声 / 说 / 著名《醉翁亭记》"有亭翼然"（名字）
《马说》"世无伯乐"（名声）		作动词时解"说"或"著名"
行走 / 做 / 行为 / 行列《马说》"千里马常有"（走）
《论语》"三人行"（行走）		读háng时解"行列"；读xíng时解"走/做"
明亮 / 明白 / 聪明 / 明辨《爱莲说》"清明"（明亮）
《出师表》"以伤伯乐之明"（英明）		多义词，需结合语境判断
居住 / 处在 / 经过《愚公移山》"面山而居"（住）
《醉翁亭记》"而年又最高"（处在）		"居"后跟时间词时常解"处在"
遗留下 / 丢失 / 给《出师表》"有所广益"（给）
《孟子》"遗尺布"（留下）		读wèi时解"给"；读yí时解"留下/丢失"
伐砍 / 讨伐 / 功绩《曹刿论战》"齐师伐我"（讨伐）
《待贾者言》"坎坎伐檀"（砍）		作"砍"讲时常与"木"搭配
发出发 / 发现 / 发作 / 打开《陈涉世家》"发闾左适戍渔阳"（征发）
《送东阳马生序》"录毕走而送之"（出发）		读fā时多"出发/发现"；读fā时"发"通"髪"
度测量 / 尺度 / 考虑《郑人买履》"先自度其足"（测量duó）
《出师表》"将军向宠，性行淑均"（尺度）		动词读duó，名词读dù
