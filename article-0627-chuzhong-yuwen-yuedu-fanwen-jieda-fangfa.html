一、阅读理解四步法

第一步：通读全文

花2-3分钟完整读一遍，了解文章大意、人物、时间、地点、事件。

第二步：圈画重点

标记每段关键句、修辞手法、情感变化词、环境描写句。

第三步：审题定位

读题目画关键词，判断题型，找准答案区间（哪一段哪一句）。

第四步：规范作答

用①②③分点，结合原文，术语准确，字迹工整。

二、记叙文满分公式

题型满分公式
标题含义表层含义（字面） + 深层含义（象征/情感/主题）
句子赏析修辞手法 + 内容概括 + 表达效果 + 思想情感
人物形象身份特征 + 性格特点 + 具体事例 + 主题关系
环境描写交代背景 + 渲染气氛 + 推动情节 + 衬托人物 + 深化主题

三、说明文满分公式

题型满分公式
说明方法方法名称 + 内容概括 + 作用分析
语言准确性词语本身作用 + 语境分析 + 去掉后果
