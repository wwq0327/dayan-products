多音字·形近字·易错字专练

一、易错字音（20题）

  1. 氛（fēn / fèn）围　答案：fēn
  2. 潜（qián / qiǎn）力　答案：qián
  3. 嫉（jí / jì）妒　答案：jí
  4. 畸（jī / qí）形　答案：jī
  5. 哺（bǔ / pǔ）育　答案：bǔ
  6. 嘲（cháo / zhāo）笑　答案：cháo
  7. 档（dàng / dǎng）案　答案：dàng
  8. 逮（dǎi / dài）捕　答案：dài（仅dài有"逮捕"义）
  9. 提（tí / dī）防　答案：dī
  10. 粘（nián / zhān）贴　答案：nián（形容词）/ zhān（动词）

二、多音字辨析（20题）

  1. 参[cān]加 / 参[cēn]差 / 海参[shēn]　答案：cān / cēn / shēn
  2. 强[qiáng]大 / 勉[qiǎng]强 / 倔强[jiàng]　答案：qiáng / qiǎng / jiàng
  3. 调[diào]查 / 调[tiáo]整　答案：diào / tiáo
  4. 冠[guān]心病 / 冠军[guàn]　答案：guān / guàn
  5. 塞[sāi]车 / 阻[sè]塞 / 边[sài]塞　答案：sāi / sè / sài
  6. 称[chēng]呼 / 称[chèn]心如意　答案：chēng / chèn
  7. 散[sǎn]步 / 散[sàn]步　答案：sǎn（懒散）/ sàn（分开）
  8. 模[mó]仿 / 模[mú]样　答案：mó / mú
  9. 兴[xīng]趣 / 高兴[xìng]　答案：xīng / xìng
  10. 传[chuán]递 / 传记[zhuàn]　答案：chuán / zhuàn

三、形近字辨析（20题）

戊（wù）· 戌（xū）· 戍（shù）—— 记忆口诀：点shù（戍），横xū（戌），撇wù（戊）

  1. 辨/辩/辫——分辨/争辩/辫子　答案：各取偏旁区分
  2. 己（jǐ）/ 已（yǐ）/ 巳（sì）—— 记忆：已封口，巳封一半，己不封
  3. 即（jí）/ 既（jì）—— 即：立即/就是 / 既：已经/既然
  4. 概（gài）/ 慨（kǎi）—— 概括/慷慨
  5. 燥（zào）/ 躁（zào）/ 澡（zǎo）—— 干燥/急躁/洗澡
  6. 治（zhì）/ 冶（yě）—— 治疗/冶炼
  7. 折（zhé）/ 拆（chāi）—— 折断/拆开
  8. 钓（diào）/ 钩（gōu）—— 钓鱼/鱼钩
  9. 歧（qí）/ 岐（qí）—— 歧路/岐山（山名专用）
  10. 瞻（zhān）/ 檐（yán）—— 瞻仰/屋檐
