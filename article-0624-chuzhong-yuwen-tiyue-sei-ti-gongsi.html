一、阅读理解万能公式

题型万能公式
标题含义表层含义 + 深层含义（象征/隐喻/情感）
句子赏析手法 + 内容 + 效果 + 情感
人物形象身份 + 性格 + 事件 + 主题
环境描写背景 + 气氛 + 情节 + 人物 + 主题
主题探究概括 + 感悟 + 联系实际

二、说明文答题公式

题型万能公式
说明方法方法名称 + 内容概括 + 作用分析
语言准确性词语作用 + 语境分析 + 去掉后果

三、议论文答题公式

题型万能公式
论点判断位置法 + 内容验证
论证方法方法名称 + 举例说明 + 论证效果

四、作文开头结尾公式

万能开头：名言/现象 + 点题 + 亮出论点
万能结尾：总结分论 + 升华主旨 + 发出号召
