一、基础知识板块

① 字音字形

类型常见考点备考建议
多音字长、发、和、行、差等根据语境判断读音
形近字戊戌戍、己巳已、辨辩辩等区分字形和字义
同音字形近义不同，需结合语境理解词义再选择

② 成语辨析

易错类型示例正确释义
望文生义不刊之论不能更改的言论
语义重复忍俊不禁地笑了本身就是笑的意思
对象错误豆蔻年华形容老人只用于十三四岁少女
色彩错误处心积虑（褒义）贬义，贬义词

③ 病句辨析

类型识别方法示例
成分残缺主语/谓语/宾语缺失通过努力，使成绩提高了
搭配不当主谓/动宾/主宾不匹配他的品质是伟大的
语序不当多层定语/状语顺序错我永远记忆那天的情景
成分赘余重复多余词语目的是为了加强
结构混乱两个句子混杂听了他的话非常感动
不合逻辑自相矛盾至少有二三个以上

二、古诗文阅读板块

① 文言文实词

高频实词常见释义
之代词/助词/动词
其代词/语气词
而连词（并列/递进/转折/因果）
于介词（在/向/对/比/从）
乃副词（才/就/竟然）
者助词（……的人/的事）
所助词（所字结构）
为动词/介词（做/因为/为了）

② 古诗词鉴赏意象

类别常见意象情感含义
思乡月亮、鸿雁、柳树、笛声思念家乡、亲人
送别长亭、杨柳、酒、孤帆依依惜别、离愁
爱国烽火、杜鹃、投笔、山河忧国忧民、建功立业
高洁梅花、菊花、青松、明月坚贞不屈、隐逸高洁
愁苦梧桐、落花、秋风、细雨孤独忧愁、韶华易逝

三、现代文阅读板块

① 记叙文阅读

题型答题公式
标题含义表层含义 + 深层含义
标题作用点明对象 + 贯穿线索 + 揭示主题 + 吸引读者
句子赏析手法 + 内容 + 效果 + 情感
人物形象身份 + 性格 + 事件 + 主题
环境描写背景 + 气氛 + 情节 + 人物 + 主题
主题探究概括 + 感悟 + 联系实际

② 说明文阅读

题型答题公式
说明方法方法名称 + 内容概括 + 作用分析
说明语言词语作用 + 语境分析 + 去掉后果 + 准确性
信息筛选找准区间 + 提取关键词 + 整理概括

③ 议论文阅读

题型答题公式
论点判断位置法（标题/开头/结尾）+ 内容验证
论证方法方法名称 + 举例说明 + 论证效果
论证思路提出问题 + 分析问题 + 得出结论

四、作文板块

① 审题立意

题型审题方法
命题作文找出关键词，确定写作范围
半命题作文补全题目，选择自己擅长的内容
材料作文找出关键词，提炼观点，选择角度
话题作文理解话题含义，确定立意方向

② 结构模板

五段式：开头点题 + 分论点1 + 分论点2 + 分论点3 + 结尾升华

③ 开头结尾模板

万能开头：

"[名言/现象/故事]，让我明白了[道理]。在我看来，[观点]。"

万能结尾：

"综上所述，[总结]。让我们[号召]，共同[美好愿景]。"
