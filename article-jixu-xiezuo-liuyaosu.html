中考语文｜记叙文写作六大要素与结构布局

记叙文是中考语文作文的主流题型。相比议论文，记叙文更考验学生的叙事能力和情感表达能力。许多学生拿到一个题目后，不知道从何入手，或者写出来的文章平淡无奇、缺乏亮点。本文系统梳理记叙文写作的六大要素、结构布局与高分技巧，帮助考生快速提升记叙文写作水平。

一、记叙文六要素

记叙文的六要素是写好记叙文的基础。中考记叙文无论是写人、写事还是写景，都必须交代清楚这六个要素。

要素内容写作要点
时间故事发生在什么时候用具体日期、季节、天气或"那天""一个周末"等表达
地点故事发生在哪里交代清楚地点环境，包括室内室外、城市乡村
人物故事涉及哪些人主要人物1-2个，次要人物配合情节出现
起因故事为什么开始简要点明原因，不可过于冗长
经过故事是怎样发展的重点部分，占全文篇幅60%以上
结果故事的结局是什么结局要出人意料又在情理之中

二、记叙文三种主要类型

类型一：写人记叙文

核心：通过一件事或多件事展现人物性格特征。

写作要点：

  • 选取典型事例（最能体现人物特点的一件事）
  • 运用多种人物描写方法（动作、语言、神态、心理）
  • 点面结合：既有整体印象，又有细节支撑
  • 结尾升华：体现人物的品格或精神

结构公式：

  1. 开头：介绍人物+初步印象（或设置悬念）
  2. 中间：用2-3个事例展开叙述，每件事侧重一个侧面
  3. 结尾：升华人物精神品质+点题

类型二：写事记叙文

核心：通过一件事表达一个中心思想。

写作要点：

  • 一件事的六要素必须完整、清晰
  • 经过部分要有波澜（困难→解决→意外→高潮）
  • 叙事要有细节描写，不能空洞
  • 结尾揭示事件的意义或感悟

结构公式：

  1. 开头：设置悬念或交代背景，引出事件
  2. 经过：按时间顺序或心理变化顺序展开
  3. 高潮：矛盾冲突或关键转折
  4. 结尾：点明事件的意义或获得的感悟

类型三：写景记叙文

核心：通过景物描写抒发情感或表达哲理。

写作要点：

  • 按一定顺序（时间、空间、游览路线）描写
  • 调动多种感官（视觉、听觉、嗅觉、触觉）
  • 融入情感：借景抒情、情景交融
  • 结尾：借景说理或抒发情感

三、开头结尾公式

高分开头公式

公式一：环境渲染式

【公式】时间地点环境描写 + 渲染氛围 + 引出人物/事件

【范例】那年冬天，雪下得特别大，整个村庄都被覆盖在一片白茫茫的世界里。我推开门，看见爷爷正站在院子里，肩上扛着那把老锄头。

公式二：悬念设置式

【公式】设置疑问/冲突/矛盾 → 吸引读者 → 引出正文

【范例】"这怎么可能？"我瞪大眼睛，难以置信地望着那张成绩单。明明我付出了那么多努力，为什么结果却如此残忍？

公式三：倒叙回忆式

【公式】从现在回到过去 → 引出回忆 → 自然过渡到事件

【范例】每当看到那棵老槐树，我就会想起那年夏天，想起和外婆在一起的那些日子。

公式四：题记点睛式

【公式】题记（一句话点题） + 过渡句 + 引出正文

【范例】"有一种温暖，叫做陪伴。"——题记
小时候，我不懂这两个字的重量。直到那一天……

高分结尾公式

公式一：感悟升华式

【公式】事件结局 + 获得感悟 + 升华中心

【范例】那一刻，我终于明白：真正的长大，不是年龄的增长，而是学会承担责任。

公式二：首尾呼应式

【公式】结尾与开头呼应 + 点题 + 深化情感

【范例】雪还在下，村庄还是那个村庄。只是站在院子里的那个人，已不再是从前的我。（呼应开头）

公式三：留白悬念式

【公式】以一个动作/场景/对话收束 → 不点明意义 → 留白让读者思考

【范例】他拿起那封信，看了又看，最后轻轻地放进抽屉里。我不知道信里写了什么，但那一天，我看到了他眼角的一滴泪。

公式四：自然收束式

【公式】叙事结束 + 简单议论收尾 + 点题

【范例】夕阳西下，我们走在回家的路上。那条小路，爸爸妈妈牵着我走过无数次，而我知道，以后我也会牵着他们的手，走过无数次。

四、记叙文高分技巧

技巧一：细节描写

核心公式：动作分解 + 感受叠加 + 环境点缀

【范例对比】

  • 平淡写法：爸爸把书递给我。
  • 高分写法：爸爸慢慢弯下腰，从床头柜最底层翻出一本泛黄的笔记本，小心翼翼地拍了拍封面上厚厚的灰尘，像是在抚摸一位老朋友，然后轻轻递到我手中。

技巧二：一波三折

核心公式：期待 → 障碍 → 解决 → 新障碍 → 高潮 → 结局

【范例】

  • 期待：我满怀信心参加了班委竞选。
  • 障碍：演讲时突然忘词，场面十分尴尬。
  • 解决：我深吸一口气，从忘词处继续往下说。
  • 新障碍：投票结果出来，我只差一票落选。
  • 高潮：我决定找班主任再争取一次机会。
  • 结局：班主任增设了一个新的职位，我成功当选。

技巧三：以小见大

核心公式：小事切入 → 细节刻画 → 升华大主题

【范例】公交车上的一次让座，看似平常，却让我看到了城市的温度。

技巧四：情感真挚

核心公式：真实情感 + 细节支撑 + 避免矫情

【写作原则】

  • 情感要真实，不编造
  • 避免过度煽情
  • 用具体事件而非抽象词语表达情感
  • 结尾感悟要自然，不说教

五、结构布局公式

公式一：五段三分式（最通用）

  • 第一段（引论）：开头，150字左右，点题
  • 第二段（本论）：事件起因+经过前半段，200字
  • 第三段（本论）：经过后半段+高潮，250字
  • 第四段（本论）：结果+初步感悟，200字
  • 第五段（结论）：升华中心+点题，150字

公式二：小标题式（结构清晰）

  • 小标题1：体现事件发展的第一阶段
  • 小标题2：体现事件发展的第二阶段
  • 小标题3：体现事件发展的高潮或结尾
  • 结尾段：升华主题

公式三：片段组合式（内容丰富）

  • 片段一：场景/人物特写（200字）
  • 片段二：另一个场景/人物（200字）
  • 片段三：核心事件详细展开（300字）
  • 结尾：升华感悟（100字）

六、真题精讲

【2024 南充中考】请以"这也是一种力量"为题，写一篇记叙文。

【写作思路】

  • 选材方向：亲情、友情、师情、陌生人的善意、传统文化等
  • 结构选择：五段三分式，以"我"为核心视角
  • 高分关键：通过具体事件展现"力量"的无形作用

【高分范文片段】

外婆的手很粗糙，布满了老茧和裂纹。但就是这双手，每天早上五点就起来，为我做早饭。我说过很多次让她休息，她总是笑笑说："闲着也是闲着。"

那天清晨，我起床时发现她又站在灶台前。蒸汽氤氲中，我看见她用那双布满裂纹的手，小心翼翼地把鸡蛋打进锅里。她的背已经驼了，手臂上青筋突起，每一个动作都显得那么吃力。我忽然明白：这就是外婆的力量——不是惊天动地，而是润物无声。

七、练习题

  1. 记叙文六要素不包括（C）
    A. 时间　B. 地点　C. 主题　D. 人物
  2. 写人记叙文的写作核心是（B）
    A. 写景　B. 通过事件展现人物性格　C. 发表议论　D. 抒发情感
  3. 下列不属于高分结尾公式的是（D）
    A. 感悟升华式　B. 首尾呼应式　C. 留白悬念式　D. 大段抒情式
  4. 记叙文开头的作用不包括（A）
    A. 大量描写景物　B. 吸引读者阅读兴趣　C. 点题　D. 引出下文
  5. 以小见大的写作技巧核心是（B）
    A. 用小事反映大主题　B. 小事切入+细节刻画+升华大主题　C. 用小事代替大事　D. 用小事说明大道理
  6. 一波三折的叙事结构中"波"指（D）
    A. 波浪　B. 海浪　C. 过程　D. 障碍和转折
  7. 细节描写的基本功是（A）
    A. 动作分解和感受叠加　B. 长篇大论　C. 大量修辞　D. 抽象描写
  8. 写景记叙文的写作顺序不包括（C）
    A. 时间顺序　B. 空间顺序　C. 因果顺序　D. 游览路线顺序

记叙文写作没有捷径，关键在于：一是积累真实素材，二是掌握基本结构公式，三是多写多改。考生在备考时要建立自己的"素材库"，积累10-20个亲身经历的小事件，考试时就能灵活运用。
