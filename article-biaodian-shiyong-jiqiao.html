前言：标点虽小，分值不少

标点符号在中考中通常以选择题或填空题形式出现，有时还会在作文评分中影响印象分。系统掌握标点用法，这些分值不容丢。

一、顿号的用法与禁区

顿号使用规则

顿号用于并列的词或词组之间，表示最短的停顿。

✓ 正确：妈妈买了苹果、梨、香蕉三种水果。

✓ 正确：那里传来笑声、喊声、哭泣声。

顿号使用禁区

禁区一：并列短语之间不用顿号

❌ 错误：我喜欢读小说、散文和诗。

✓ 正确：我喜欢读小说、散文和诗。（最后两项之间用"和"，不用顿号）

禁区二：嵌套词语之间不用顿号

❌ 错误：大楼里住着工人、农民、干部等。

✓ 正确：大楼里住着工人、农民、干部等。（"等"前不用顿号）

禁区三：概数之间不用顿号

❌ 错误：三、四十岁

✓ 正确：三四十岁（相邻数字连用表示概数，中间不用顿号）

二、逗号的使用规范

逗号用于句子内部的各种停顿，是使用频率最高的标点。

✓ 主语较长时，主语后用逗号：「北京，我们的首都，是一座美丽的城市。」

✓ 复句内分句之间用逗号：「天渐渐黑了，路灯亮了。」

三、分号的使用要点

分号用于复句中并列分句之间，或非并列关系的多重复句中。

✓ 正确：信任是金，猜疑是银；真诚是宝，虚伪是草。

✓ 正确：先去排队；再去挂号。

四、冒号的使用规范

冒号用于总说性话语之后，引起下文的分说。

✓ 正确：语文学习包括三个方面：阅读、写作、口语。

✓ 正确：他说：「我明天来。」

注意：冒号在"某某说"之后，如果"说"在中间或末尾，不用冒号。

五、引号的特殊用法

✓ 直接引用：「人生自古谁无死，留取丹心照汗青。」

✓ 强调特定词语：我们要学习"女排精神"。

✓ 讽刺或否定：所谓"聪明"，不过如此。

六、问号的正确使用

选择问句中，主语较长时主语后用问号，其他情况只在句末用问号。

✓ 正确：你是今天来，还是明天来？

✓ 错误：你来不来？

✓ 正确：你来不来的？

七、括号的使用

括号内的内容是对前文的注释或补充，可以放在句中或句末，但不对句子进行语法分析。

✓ 句中括号：「那座山（山顶有古塔）很美。」

✓ 句末括号：「他很勇敢（这在村里是出了名的）。」

八、标点综合辨析题

题目：下列句子中标点使用正确的一项是？

A. 老师走进了教室，同学、老师都静了下来。

B. 这是一年中最好的季节：春天；夏天。

C. 这个问题吗？其实很简单。

D. 「你来吗？」小明问。

答案：D

A错："同学"后应用"和"；B错："春天"后不应用分号；C错：问号应改为逗号。
