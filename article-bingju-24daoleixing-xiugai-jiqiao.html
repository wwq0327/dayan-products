中考语文病句辨析24大类型及修改技巧（一看就会）

适用对象：全国各省市中考考生  难度等级：⭐⭐（中等）

病句辨析是中考语文基础部分的高频考点，一般占4-8分。本文系统梳理24类病句类型，配以典型错误与修改示例，帮助学生建立系统的病句辨析能力，做到快速判断、准确修改。

类型1-6：成分残缺/多余
类型7-12：语序不当
类型13-18：搭配不当
类型19-24：结构混乱/不合逻辑

一、成分残缺类（6种）

类型1：主语残缺
✗ 由于他学习刻苦，使他取得了很大的进步。
✓ 他由于学习刻苦，取得了很大的进步。
病因："由于……使"造成主语残缺。删除"使"或"由于"，让"他"成为主语。
类型2：谓语残缺
✗ 同学们都要树立艰苦朴素的精神。
✓ 同学们都要树立艰苦朴素的思想（或：都要养成艰苦朴素的作风）。
病因：宾语中心语残缺。"树立"什么？缺宾语，"精神"不能与"树立"搭配，应改为"思想"或"作风"。
类型3：宾语残缺
✗ 老师反复强调要养成认真。
✓ 老师反复强调要养成认真的习惯。
病因："养成"后面缺宾语中心语，应补上"习惯"或"作风"等。
类型4：介词残缺
✗ 在学习上，我们要不断进步。
✓ 在学习上，我们要不断取得进步。
病因："不断"后缺谓语动词，与"进步"搭配的应为"取得"，整句缺少完整谓语。
类型5：关联词语残缺
✗ 他成绩很好，他不骄傲。
✓ 他成绩虽然很好，但是他不骄傲。
病因：两个分句之间缺少表转折的关联词，应在第二句前加"但是/然而"。
类型6：定语残缺
✗ 我们要有分析问题解决问题的能力。
✓ 我们要有分析问题和解决问题的能力。
病因："分析问题"和"解决问题"之间缺连词"和"，导致并列不当。

二、成分多余类（6种）

类型7：主语多余
✗ 我的母亲和我的母亲一样勤劳。
✓ 我的母亲和（或：一样勤劳的）母亲一样勤劳。或：母亲和母亲一样勤劳。
病因：主语重复，"我的母亲"出现两次，应删除一个。
类型8：谓语多余
✗ 我们一定要尽力完成这项任务。
✓ 我们一定要完成这项任务。（或：我们要尽力完成这项任务。）
病因："一定"和"尽力"语义重复，保留一个即可。
类型9：宾语多余
✗ 大家要提倡节约用水的好习惯。
✓ 大家要提倡节约用水的好习惯。（或：大家要养成节约用水的好习惯。）
病因："节约用水"本身就是好习惯，"好习惯"多余；或"提倡"后缺"……的习惯"，保留"养成"。
类型10：修饰语多余
✗ 昨晚，大约有二十多个学生参加了比赛。
✓ 昨晚，有二十多个学生参加了比赛。（或：昨晚，大约有二十名学生参加了比赛。）
病因："大约"和"多"语义矛盾，只能保留一个；"有"后可保留"多"。
类型11：关联词语多余
✗ 因为他学习很努力，所以因此取得了好成绩。
✓ 因为他学习很努力，所以取得了好成绩。
病因："因为……所以"是固定搭配，但"因此"是"因为+结果"的整体，不能与"所以"叠用。
类型12：数量词多余
✗ 我们班至少有二十多个学生获奖。
✓ 我们班至少有二十个学生获奖。（或：我们班有二十多个学生获奖。）
病因："至少"表示最低限度，后面用确数；"二十多个"是约数，不能与"至少"叠用。

三、语序不当类（6种）

类型13：多项定语次序不当
✗ 这是一个非常好的美丽的花园。
✓ 这是一个非常美丽的花园。
病因：多项定语堆叠，"非常好"和"美丽"语义相近，应合并为一个形容词。
类型14：定语状语混淆
✗ 我们要有认真克服困难的决心。
✓ 我们要有认真克服困难的决心。（"认真"应为"认真地"修饰"克服"）
病因："认真"应作状语修饰"克服"，说成"认真克服"而非定语修饰"决心"，此句实为定语位置不当。
类型15：关联词语位置不当
✗ 不仅老师表扬了他，而且同学们也表扬了他。
✓ 不仅老师表扬了他，同学们也表扬了他。
病因："不仅……而且"连接两个主语时，"不仅"应置于主语后，即"老师不仅……，同学们……"。
类型16：时间顺序不当
✗ 解放后，我们家乡的面貌比解放前有了很大进步。
✓ 解放后，我们家乡的面貌有了很大进步，比解放前好了很多。
病因：语序混乱，"比解放前"应置于"有了很大进步"之后。
类型17：因果倒置
✗ 因为他生病了，所以没有上学，因为他没有上学，所以成绩下降了。
✓ 因为他生病了，所以没有上学；因为没有上学，所以成绩下降了。
病因：两个因果链条之间语序混乱，第二句的"因为没有上学"应接续"没有上学"的原因，而非与第一句并列。
类型18：先后顺序不当
✗ ，我们要发扬优点，改正缺点。
✓ 我们要改正缺点，发扬优点。
病因："改正缺点"应在"发扬优点"之前，符合认识规律（先改后扬）。

四、搭配不当类（6种）

类型19：主谓搭配不当
✗ 他的脚步声打破了深夜的寂静。
✓ 他的脚步声划破了深夜的寂静。（或：他的身影打破了深夜的寂静。）
病因："脚步声"不能"打破"寂静，"打破"的施动者一般是人或具体事物，应改为"划破"或换主语为"身影"。
类型20：动宾搭配不当
✗ 我们要维持教室的整洁，不乱扔粉笔。
✓ 我们要维持教室的整洁，不乱放粉笔。（或：不要乱扔粉笔。）
病因："维持"与"整洁"搭配，但"整洁"是状态不是动作；"乱扔粉笔"与"维持整洁"逻辑矛盾，应用"保持整洁"。
类型21：中心语与修饰语搭配不当
✗ 他有非常魁梧強壮的身体。
✓ 他有非常魁梧强壮的身体。（或：他有魁梧的身材。）
病因："魁梧"和"强壮"都可形容身体，但"魁梧"侧重身高肩宽，"强壮"侧重体格健壮，两者并用略显重复且搭配不当。
类型22：前后矛盾
✗ 这次考试，我们班几乎所有同学都及格了，只有个别不及格。
✓ 这次考试，我们班大多数同学都及格了，只有个别不及格。
病因："几乎所有"和"只有个别"矛盾，"几乎所有"包含全部，"个别不及格"意味着不是全部，应改为"大多数"。
类型23：肯定否定不当
✗ 他无法否认他不是不认真。
✓ 他无法否认他是认真的。（或：他不得不承认他不认真。）
病因：三重否定造成语义混乱，"无法否认"（=不能否认）+ "不是不认真"（=认真），变成"不能否认他是认真的"，应简化。
类型24：两面对一面不当
✗ 能否努力学习，是取得好成绩的关键。
✓ 能否努力学习，是能否取得好成绩的关键。（或：努力学习，是取得好成绩的关键。）
病因："能否"是两面对"是……关键"的一面，应保持对应，或去掉"能否"统一为肯定表述。
⚠️ 中考病句辨析快速判断口诀：

看主谓宾是否齐全，问搭配是否合理，查语序是否顺畅，读逻辑是否通顺。

做题时用"紧缩法"：先找主干（主谓宾），再看枝叶（定状补），最后分析搭配关系。

📝 修改病句的原则与方法

原则：保留原意，少量修改，多样不改。

方法：①成分残缺——补上缺少的成分；②成分多余——删除多余成分；③语序不当——调整排列顺序；④搭配不当——更换搭配不当的词；⑤结构混乱——重新组织句子；⑥不合逻辑——纠正逻辑错误。

答题格式：一般先判断病句类型，再写出修改后的正确句子。
