中考语文名句默写分类整理

适用年级：初三（南充中考） | 分值：约8-10分 | 范围：初中全部重点名句

名句默写是送分题，但也是丢分重灾区。这份按主题分类整理，帮你高效复习，送分题稳稳拿满。

一、励志奋斗类

1. 长风破浪会有时，直挂云帆济沧海。——李白《行路难》

易错："济"不要写成"挤"

2. 人生自古谁无死？留取丹心照汗青。——文天祥《过零丁洋》

易错："汗"不要写成"汉"，"青"不要写成"清"

3. 会当凌绝顶，一览众山小。——杜甫《望岳》

易错："凌"不要写成"陵"

4. 少壮不努力，老大徒伤悲。——汉乐府《长歌行》

5. 沉舟侧畔千帆过，病树前头万木春。——刘禹锡《酬乐天扬州初逢席上见赠》

6. 宝剑锋从磨砺出，梅花香自苦寒来。——《警世贤文》

二、读书学习类

1. 书山有路勤为径，学海无涯苦作舟。——韩愈

2. 读书破万卷，下笔如有神。——杜甫《奉赠韦左丞丈二十二韵》

3. 学而不思则罔，思而不学则殆。——孔子《论语》

易错："罔"不要写成"惘"，"殆"不要写成"贻"

4. 纸上得来终觉浅，绝知此事要躬行。——陆游《冬夜读书示子聿》

5. 旧书不厌百回读，熟读深思子自知。——苏轼

三、情感亲情类

1. 举头望明月，低头思故乡。——李白《静夜思》

2. 但愿人长久，千里共婵娟。——苏轼《水调歌头》

易错："婵"不要写成"禅"，"娟"不要写成"捐"

3. 独在异乡为异客，每逢佳节倍思亲。——王维《九月九日忆山东兄弟》

4. 谁言寸草心，报得三春晖。——孟郊《游子吟》

易错："晖"不要写成"辉"

5. 烽火连三月，家书抵万金。——杜甫《春望》

四、哲理思辨类

1. 人生得意须尽欢，莫使金樽空对月。——李白《将进酒》

2. 山重水复疑无路，柳暗花明又一村。——陆游《游山西村》

3. 问渠那得清如许？为有源头活水来。——朱熹《观书有感》

4. 不识庐山真面目，只缘身在此山中。——苏轼《题西林壁》

5. 落红不是无情物，化作春泥更护花。——龚自珍《己亥杂诗》

6. 旧时王谢堂前燕，飞入寻常百姓家。——刘禹锡《乌衣巷》

五、景物描写类

1. 大漠孤烟直，长河落日圆。——王维《使至塞上》

易错："圆"不要写成"园"

2. 枯藤老树昏鸦，小桥流水人家，古道西风瘦马。——马致远《天净沙·秋思》

3. 月落乌啼霜满天，江枫渔火对愁眠。——张继《枫桥夜泊》

4. 日出江花红胜火，春来江水绿如蓝。——白居易《忆江南》

六、忧国忧民类

1. 先天下之忧而忧，后天下之乐而乐。——范仲淹《岳阳楼记》

易错："后"不要写成"候"

2. 僵卧孤村不自哀，尚思为国戍轮台。——陆游《十一月四日风雨大作》

3. 人生自古谁无死？留取丹心照汗青。——文天祥《过零丁洋》

4. 剑外忽传收蓟北，初闻涕泪满衣裳。——杜甫《闻官军收河南河北》

默写丢分原因：

1. 写错别字（最常见）：如"汗青"写成"汉青"

2. 丢字落字：如"千里共婵娟"写成"千里婵娟"

3. 写繁体字：答题要用简化字

4. 位置写错：上下句搞混

复习建议：

1. 先背再写，写完检查

2. 易错字要特别记忆

3. 不确定的不写，写了就要写对

4. 字迹工整，卷面整洁
