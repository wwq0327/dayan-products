一、记叙文阅读套路

题型满分公式
标题含义表层含义 + 深层含义
句子赏析修辞手法 + 内容概括 + 表达效果 + 思想情感
人物形象身份特征 + 性格特点 + 具体事例 + 主题关系
环境描写交代背景 + 渲染气氛 + 推动情节 + 衬托人物 + 深化主题
情节概括什么人+做什么事+结果如何

二、说明文阅读套路

题型满分公式
说明方法方法 + 内容 + 作用
语言准确性词语 + 语境 + 去掉后果
段落作用结构 + 内容 + 上下关联
