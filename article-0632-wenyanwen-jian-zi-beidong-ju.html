📜 文言文被动句"见"字结构解析

见…于 · 被…所 · 以…见… | 大衍语文店

什么是被动句？

被动句是指主语是动作的承受者（即受事者）的句式。与主动句不同，被动句的主语不是动作的实施者，而是动作的承受者。

主动句：屈原创作了《离骚》。

被动句：《离骚》被屈原创作了。→ 实际上更规范的表达是：《离骚》为屈原所创作。

在文言文中，被动句有很多特殊的表达形式，其中"见"字结构是最重要的一类。

一、"见"字被动句的四大类型

类型一：见 + 动词（直接被动）

格式：见 + 动词

主语 + 见 + 动词，表示主语承受了该动作。翻译时在动词前加"被"。

格式：主语 + 见 + 动词 → 主语 + 被 + 动词（+ by 施事者）
例句翻译
信而见疑，忠而被谤诚信却被怀疑，忠贞却被诽谤
盆成括见杀盆成括被杀
弥子瑕见爱于卫君弥子瑕被卫君宠爱
注意："见"字在这里没有"看见"的意思，而是表示被动，相当于"被"。

类型二：见 + 动词 + 于 + 施事者（典型"见…于…"句式）

格式：见 + 动词 + 于 + 施事者

这是文言文中最典型、最常见的"见"字被动句式。"于"字引出动作的实施者（施事者）。

格式：主语 + 见 + 动词 + 于 + 施事者 → 主语 + 被 + 动词 + (by) + 施事者
例句翻译
臣诚恐见欺于王而负赵我确实害怕被大王欺骗而辜负赵国
吾长见笑于大方之家我长久地被内行人笑话
今是大臣见犯，乃此也现在大臣们被冒犯，就是这个原因
是以见放因此被放逐

类型三：为 + 施事者 + 所 + 动词（"被…所…"结构）

格式：为 + 施事者 + 所 + 动词

这是文言文中最典型的"被"字被动句，"为"引出施事者，"所"是助词无实义。

格式：主语 + 为 + 施事者 + 所 + 动词 → 主语 + 被 + 施事者 + 动词
例句翻译
为秦王之所欲被秦王想要
身客死于秦，为天下笑自身在秦国死去，被天下人嘲笑
恐为操所先害怕被曹操抢先
赢兵为人马所蹹藉溃败的士兵被人马踩踏

类型四：见于…（"被…所…"的变体）

格式：为 + 动词 + 所见（少见）

这是一种特殊的被动表达，较为少见。

补充：其他被动标志词

标志词例句说明
被仍被县官所患直接用"被"，与现代汉语相近
为为天下笑"为"直接表被动
于困于心，衡于虑"于"引出施事成分
以以资事敌"以"表被动（少见）

二、"见"字被动句的判断方法

四步判断法：
① 看主语：主语是动作的承受者（受事）还是实施者（施事）？
② 找"见"：句中是否有"见"字出现？
③ 看结构：是否符合"见+动"或"见+动+于"结构？
④ 译"被"意：能否翻译成"被…"

三、易混辨析：见"被"字不等于被动

用法含义例句
见 + 动词（被动）被…信而见疑（被怀疑）
见 + 动词（指代性）我/你（用在动词前，指代动作对象）君既若见录（你既然这样记着我）
见 + 动词（显示）显现、呈现图穷匕见（地图展开，匕首显现）
冀君见谅希望（希望对方）原谅我"见"指代"我"
重要区别："见"字在句中是表被动还是指代第一人称？要根据上下文判断。如果"见"后动词的主语是"见"所指代的对象，则"见"是指代性副词；如果主语是动作的承受者，则是被动标志。

四、中考真题练习

判断下列句子的句式（主动句/被动句）：

① 信而见疑，忠而被谤，能无怨乎？

→ 被动句，"见疑"即"被怀疑"，"被谤"即"被诽谤"。

② 臣诚恐见欺于王而负赵。

→ 被动句，"见欺于王"即"被大王欺骗"。

③ 举世混浊而我独清，众人皆醉而我独醒。

→ 主动句，"我"是动作"清"和"醒"的实施者。

五、翻译要点总结

句式翻译公式示例
见 + 动被 + 动词见杀 → 被杀
见 + 动 + 于被 + 动词 + (by) + 施事者见笑于大方 → 被内行人笑话
为 + 所 + 动被 + 施事者 + 动词为秦所困 → 被秦国围困
为 + 动 + 于被 + 动词 + (by) + 施事者为天下笑 → 被天下人嘲笑
翻译小技巧：遇到"见"字被动句时，先把"见"翻译成"被"，再找施事者（"于"后或"所"前的成分），最后补全动词意思，整个句子就清晰了。
