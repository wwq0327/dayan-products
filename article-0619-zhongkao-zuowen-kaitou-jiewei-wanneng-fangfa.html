一、开头结尾为什么重要

中考作文评分时间只有短短几十秒，开头决定阅卷老师的第一印象，结尾决定最终得分档次。一个好的开头能让作文瞬间提升2-3分，一个好的结尾能让作文稳拿一类文。

二、12种万能开头写法

① 悬念式开头

公式：描述反常现象 + 设置悬念 + 引出下文

示例："那天夜里，我分明听到了隔壁传来的哭声。可第二天，妈妈却笑着说一切安好。这背后，究竟藏着什么秘密？"

② 倒叙式开头

公式：从结果/结局写起 + 回忆过程 + 揭示真相

示例："那张泛黄的旧照片，至今仍摆在书桌最显眼的位置。每当我看到它，就会想起那段刻骨铭心的日子。"

③ 景物渲染式开头

公式：描写特定景物 + 借景抒情 + 引出人物

示例："窗外，那棵老槐树又开花了。洁白的花瓣在风中摇曳，仿佛在诉说着什么。我的思绪，也随之飘回了那个夏天。"

④ 名言引用式开头

公式：引用名言/诗句 + 解读内涵 + 引出话题

示例："'长风破浪会有时，直挂云帆济沧海。'李白这句诗曾激励过无数人。而在我的成长路上，也有一盏灯，照亮我前行的方向。"

⑤ 比喻式开头

公式：用比喻句点题 + 生动形象 + 引出下文

示例："如果说人生是一本书，那么挫折便是其中最精彩的章节；如果说人生是一场戏，那么困难便是最动人的台词。"

⑥ 排比式开头

公式：三组以上排比句 + 气势充沛 + 点明主题

示例："爱心是一缕阳光，照亮黑暗的角落；爱心是一泓清泉，滋润干涸的心田；爱心是一首赞歌，奏响生命的旋律。"

⑦ 人物描写式开头

公式：描写人物外貌/动作 + 突出特点 + 引出故事

示例："他总是穿着一件洗得发白的蓝布衫，脊背微微佝偻，但眼神却格外明亮。每当看到他在校门口扫地，我的心便涌起一股暖流。"

⑧ 对比式开头

公式：对比两种情况 + 突出反差 + 引出主题

示例："曾经，我以为幸福是拥有无尽的财富；如今，我终于明白，幸福是清晨母亲端来的那碗热粥，是深夜父亲披在我身上的那件外套。"

⑨ 数字式开头

公式：用数字制造画面感 + 突出主题 + 引出下文

示例："1000多个日夜，30000多公里路，2000多顿饭——这是父亲送我上学的记录。每一组数字背后，都藏着一个关于爱的故事。"

⑩ 声音式开头

公式：描写特定声音 + 制造画面感 + 引出回忆

示例："'咯吱——'那扇老木门又响了。这个声音，我听了十二年。每一声，都记载着奶奶对我的牵挂。"

⑪ 开门见山式开头

公式：直接点题 + 简洁有力 + 明确中心

示例："成长是什么？成长是跌倒后重新站起，是失败后不放弃，是黑暗中寻找光明。成长的滋味，只有亲身经历才能体会。"

⑫ 疑问式开头

公式：提出问题 + 引发思考 + 引出下文

示例："人为什么要善良？这个问题困扰了我很久。直到那天，我在雨中看到了那个陌生人为我撑起的伞。"

三、12种万能结尾写法

① 总结升华式结尾

公式：总结全文 + 升华主旨 + 发出号召

示例："那把伞，为我撑起了一片晴空。而我，也愿成为别人的一把伞，在风雨中为他们遮风挡雨。这，就是爱的传递。"

② 首尾呼应式结尾

公式：回扣开头关键词 + 深化主题 + 完整结构

示例："那扇老木门，咯吱声依旧。但我知道，那声音里承载的，是奶奶对我无尽的关爱。这份爱，我会永远珍藏。"

③ 留白式结尾

公式：描述画面 + 戛然而止 + 意味深长

示例："夕阳西下，外婆站在老屋门口向我挥手。她的身影在余晖中渐渐模糊，但我知道，有些东西，永远不会褪色。"

④ 抒情议论式结尾

公式：直接抒情 + 表达感悟 + 升华主题

示例："那一刻，我终于读懂了父亲沉默的爱。他的背影，是世界上最美的风景。"

⑤ 引用式结尾

公式：引用名言/诗句 + 呼应主题 + 画龙点睛

示例："'谁言寸草心，报得三春晖。'母亲的恩情我无以为报，唯有珍惜当下，不负韶华。"

⑥ 比喻式结尾

公式：用比喻收尾 + 生动形象 + 强化主题

示例："如果说母爱是一盏灯，那么父亲便是那灯下默默添油的人。他们共同照亮了我人生的道路。"

⑦ 排比式结尾

公式：排比收尾 + 气势充沛 + 强化情感

示例："我感谢父母，感谢他们的养育之恩；我感谢老师，感谢他们的教诲之情；我感谢朋友，感谢他们的陪伴之谊。"

⑧ 哲理式结尾

公式：提炼生活哲理 + 表达人生感悟 + 升华主旨

示例："生活就像一面镜子，你对它笑，它就对你笑。在人生的道路上，唯有保持积极乐观的心态，才能收获属于自己的精彩。"

⑨ 梦境式结尾

公式：描述梦境/想象 + 表达愿望 + 意味深长

示例："那天晚上，我做了一个梦。梦里，奶奶还是那么年轻，她笑着向我招手。我想，那一定是另一个世界，她在那里等我。"

⑩ 行动式结尾

公式：表明决心 + 付诸行动 + 展望未来

示例："从今以后，我决定不再虚度光阴。我要用汗水浇灌梦想，用行动书写青春。"

⑪ 场景描写式结尾

公式：描写特定场景 + 渲染气氛 + 强化情感

示例："窗外，夕阳将天空染成橘红色。爷爷坐在藤椅上，眯着眼望向远方。那一刻，时间仿佛静止了。"

⑫ 反问式结尾

公式：反问句收尾 + 加强语气 + 引人深思

示例："谁说少年不识愁滋味？在我看来，每一代人都有自己的青春与梦想。而我，正走在属于自己的路上。"

四、开头结尾速背模板

亲情类开头结尾

开头：那天，[具体场景描写]，让我明白了[亲人特点]。
结尾：那一刻，我终于理解了[亲人称呼]的[情感特点]。这份[情感名词]，我会永远珍藏。

成长类开头结尾

开头：人生就像[比喻]，而我正在经历[成长事件]。
结尾：经过这件事，我明白了[成长感悟]。在未来的日子里，我会[决心]。

励志类开头结尾

开头："[名言诗句]"，这句话一直激励着我。
结尾：我相信，只要[信念]，就一定能[目标]。

五、注意事项

  • 开头不超过150字，简洁有力，快速入题
  • 结尾不超过100字，画龙点睛，不要拖沓
  • 开头结尾要呼应，形成完整结构
  • 避免空喊口号，要有真情实感
  • 适当使用修辞，增加文采
