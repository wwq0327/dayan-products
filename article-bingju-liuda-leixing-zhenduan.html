🔍 病句修改6大类型

诊断公式+专项训练50题

类型一：成分残缺

句子里缺少了必不可少的成分（主语、谓语、宾语）。

✗ 错误例句：通过这次活动，使我深刻认识到团结的重要性。
✓ 修改：这次活动，使我深刻认识到团结的重要性。
或：通过这次活动，我深刻认识到团结的重要性。
诊断公式

看到"通过/由于/经过"等介词打头，检查主语是否被介词结构掩盖。删"通过"或删"使"。

类型二：成分赘余

句子中有多余的词语，意思重复了。

诊断公式

一看"大约/左右/余/将近/以上"等词是否与具体数字重复
二看"目的是为了""目的是为了"是否重复
三看"的目的是""其目的是"是否重复

✗ 错误例句：学校的图书馆面积约三千平方米左右，藏书近二十万册左右。
✓ 修改：学校的图书馆面积约三千平方米，藏书近二十万册。

类型三：搭配不当

词语之间的搭配不符合语言习惯或逻辑。

诊断公式

主谓搭配：检查"……发展""……提高""……增加"等是否与主语匹配
动宾搭配：检查"……提高水平""……增强体质"等是否合理
修饰语与中心语：检查"……改善了……问题"等

✗ 错误例句：我们要不断改善自己的生活习惯和工作能力。
✓ 修改：我们要不断改善自己的生活习惯和提高工作能力。

类型四：语序不当

词语的顺序排列不符合语言习惯。

诊断公式

多项定语：范围（大的/小的）→数量 →形容词 →名词
多项状语：时间 →地点 →范围 →情态 →对象
逻辑顺序：先整体后局部、先主后次、先因后果

✗ 错误例句：我们必须认真研究、刻苦学习，立刻改正缺点。
✓ 修改：我们必须认真研究、刻苦学习，迅速改正缺点。

类型五：结构混乱

把两种不同的句式混杂在一起，造成结构混乱。

诊断公式

看句子是否混用了"……的原因是……"和"……是由于……"
看是否把"根据……结论"和"……表明……"混用
检查介词结构是否杂糅

✗ 错误例句：造成这次事故的原因主要是由于操作不当。
✓ 修改：造成这次事故的原因主要是操作不当。
或：这次事故的主要原因是由于操作不当。

类型六：表意不明

句子表达的意思不清楚、不明确。

诊断公式

指代不明："他""她""它"指代不清楚
词义不明：多义词在句中产生歧义
停顿不明：不同停顿产生不同理解

✗ 错误例句：开刀的是他的父亲。
✓ 修改：为他父亲开刀的是医生。
给他开刀的是他的父亲。

快速判断口诀

  • 看到介词（通过/由于/经过）打头 → 检查主语残缺
  • 看到数字+约/左右 → 检查成分赘余
  • 看到动宾结构 → 检查搭配是否得当
  • 看到多项定语/状语 → 检查语序
  • 看到两个句式混用 → 检查结构混乱
  • 看到指代词 → 检查指代是否明确
